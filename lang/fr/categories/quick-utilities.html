Architecture de domaine et normes de confidentialité

Les outils de productivité OmniTools utilisent des interfaces matérielles de navigateur natives, notamment l'API Web Audio pour la synthèse audio du métronome sans latence, l'API de cryptographie Web pour la génération de phrase secrète CSPRNG et l'API Navigation Timing pour les diagnostics de latence en temps réel.

Questions fréquentes

Dans quelle mesure le générateur de mots de passe est-il sécurisé ?

Il utilise la norme cryptographique window.crypto.getRandomValues() du navigateur, garantissant une véritable entropie pseudo-aléatoire cryptographiquement sécurisée.

Où le Scratchpad stocke-t-il mes notes ?

Les notes sont stockées dans le bac à sable window.localStorage local de votre navigateur. Ils restent sur votre appareil même si vous fermez l'onglet.
