Architecture de domaine et normes de confidentialité

Les outils de style visuel souffrent souvent d’une mauvaise compatibilité entre navigateurs. OmniTools génère du code CSS3 propre et conforme aux normes, exploitant les variables CSS, Flexbox, Grid et les espaces colorimétriques modernes. Le traitement des images dans le navigateur s'exécute via des contextes HTML5 Canvas 2D sans aucun téléchargement dans le cloud.

Questions fréquentes

Mes images sont-elles téléchargées sur un serveur cloud lors du redimensionnement ou du recadrage ?

Non. Les images sont rendues et modifiées directement dans la mémoire HTML5 Canvas de votre navigateur. Vos photos ne quittent jamais votre appareil.

Les styles CSS générés sont-ils compatibles avec les navigateurs modernes ?

Oui, tous les extraits CSS sont optimisés pour les normes Web modernes, notamment Flexbox, CSS Grid, les variables CSS et les préfixes multi-navigateurs.
