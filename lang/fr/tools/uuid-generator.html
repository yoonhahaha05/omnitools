Présentation générale et mécanique algorithmique

Le générateur d'UUID OmniTools crée des identifiants universels uniques version 4 cryptographiquement sécurisés en stricte conformité avec la RFC 4122. Un UUID version 4 contient 128 bits de données, dont 122 bits générés à partir d'un générateur de nombres pseudo-aléatoires cryptographiquement sécurisé (CSPRNG), 4 bits réservés pour l'identifiant de version (`0100` = version 4) et 2 bits pour la variante RFC 4122 (`10` = variante 1). La probabilité de générer deux UUID v4 identiques (une collision) est infinitésimale : environ 1 sur 2 $^{122}$ (ou environ 1 sur 5,3 $ \times 10^{36}$). Même en générant 1 milliard d’UUID par seconde pendant 100 ans, la probabilité d’une duplication reste inférieure à un sur un milliard. Le générateur utilise crypto.getRandomValues() dans le navigateur.

Exemples d'usage

  • Clés primaires de base de données : Génération d'ID d'entité non séquentiels uniques au monde sur des clusters de bases de données distribuées (PostgreSQL, MongoDB, CockroachDB).
  • Traçage distribué et observabilité : Attribution d'ID de requête uniques (X-Correlation-ID) dans les en-têtes HTTP du microservice.
  • Gestion des sessions et des jetons : Creating unguessable nonce values and secure temporary transaction tokens.

Terminal et équivalents de code pour la génération d'UUID

CLI Bash/Terminal :
# Generate v4 UUID in Linux / macOS
uuidgen

# Generate lowercase v4 UUID via python
python3 -c "import uuid; print(uuid.uuid4())"
Python3 :
import uuid

# Generate RFC 4122 v4 UUID
new_id = uuid.uuid4()
print(f'Standard UUID: {new_id}')
print(f'Hex digits: {new_id.hex}')
JavaScript/Node.js :
// Native Web Crypto UUID (Browser & Node.js 16+)
const uniqueId = crypto.randomUUID();
console.log(uniqueId);

Questions fréquentes

Qu'est-ce qu'un UUID v4 ?

Un UUID version 4 est un identifiant de 128 bits généré à l'aide de nombres aléatoires avec une probabilité de collision négligeable.

Deux utilisateurs peuvent-ils générer le même UUID v4 ?

Statistiquement impossible dans des conditions normales de fonctionnement. Avec 122 bits d'entropie véritable, il existe 5,3 $ \times 10^{36}$ de combinaisons possibles, ce qui dépasse largement le nombre d'étoiles dans l'univers observable.

Pourquoi les UUID sont-ils formatés avec des tirets (8-4-4-4-12) ?

Le regroupement hexadécimal standard 8-4-4-4-12 représente les sous-champs historiques des UUID de la version 1 (time_low, time_mid, time_hi_and_version, clock_seq, node) tels que définis dans la RFC 4122.

Les UUID générés sont-ils enregistrés ou suivis ?

Jamais. Generation s'exécute à 100 % localement sur votre machine via le sous-système de cryptographie Web de votre navigateur.
