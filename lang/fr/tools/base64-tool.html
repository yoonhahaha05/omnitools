Présentation générale et mécanique algorithmique

L'encodeur et décodeur OmniTools Base64 convertit les données binaires et chaînes en représentations ASCII base-64 conformément à la RFC 4648. L'encodage Base64 prend 3 octets de données binaires (24 bits) et les mappe en 4 caractères ASCII imprimables (6 bits chacun) choisis dans une table d'index de 64 caractères (A-Z, a-z, 0-9, +, /). Lorsque le nombre d'octets d'entrée n'est pas divisible par 3, des caractères de remplissage '=' sont ajoutés pour maintenir l'alignement. Les standards JavaScript btoa et atob lancent des caractères en dehors de Latin-1. Cet encodeur transforme d'abord le texte en octets UTF-8, donc en lettres accentuées et en emoji aller-retour. Le mode sécurisé pour les URL remplace + par - et / par _.

Exemple travaillé. Encodez le mot OmniTools. Le résultat est T21uaVRvb2xz. Le décodage de cette chaîne renvoie OmniTools. Le mot fait 9 octets, ce qui se divise également par 3, donc il n'y a pas de remplissage =.

Exemples d'usage

  • Développement Web et API : Encodage des en-têtes d'autorisation d'authentification de base (`Authorization: Basic `).
  • URI de données et actifs en ligne : Intégration de petites icônes, polices et images SVG directement dans des fichiers CSS et HTML.
  • Sérialisation des données : Transmission en toute sécurité de charges utiles binaires via des canaux de transmission texte uniquement (JSON, XML, e-mail).

Terminal et équivalents de code pour l'encodage et le décodage Base64

CLI Bash/Terminal :
# Encode string to Base64 in Bash
echo -n "OmniTools" | base64

# Decode Base64 string
echo "T21uaVRvb2xz" | base64 --decode
Python3 :
import base64

# Unicode-safe Base64 in Python
encoded = base64.b64encode('OmniTools 🚀'.encode('utf-8')).decode('ascii')
decoded = base64.b64decode(encoded).decode('utf-8')
print(f'Encoded: {encoded} -> Decoded: {decoded}')
JavaScript/Node.js :
// Node.js Buffer Base64
const str = 'OmniTools 🚀';
const b64 = Buffer.from(str, 'utf-8').toString('base64');
const original = Buffer.from(b64, 'base64').toString('utf-8');
console.log({ b64, original });

Questions fréquentes

Qu'est-ce que Base64 sécurisé pour les URL ?

Base64 sécurisé pour les URL remplace « + » par « - » et « / » par « _ », et supprime les signes de remplissage de fin « = ».

Est-ce que Base64 chiffre mes données ?

Non. Base64 est un système de codage, PAS un cryptage. N’importe qui peut décoder instantanément une chaîne Base64. N'utilisez jamais Base64 seul pour protéger les mots de passe, les clés ou les informations d'identification sensibles.

Pourquoi Base64 augmente-t-il la taille des données d'environ 33 % ?

Base64 représente 3 octets (24 bits) de données utilisant 4 caractères ASCII (32 bits). Ce rapport 4:3 crée naturellement une expansion des frais généraux d'environ 33,3 %.

Puis-je encoder des fichiers binaires en toute sécurité ?

Oui. Notre API FileReader côté client lit les fichiers binaires directement dans les tampons Uint8Array, garantissant une fidélité octet par octet sans perte de données.
