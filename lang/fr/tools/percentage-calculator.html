Présentation générale et mécanique algorithmique

La page comporte trois calculs.

Un pourcentage d’un nombre équivaut à (pourcentage / 100) fois le nombre. Le pourcentage d'un nombre par rapport à un autre est (partie/tout) fois 100. Le changement d'un ancien nombre à un nouveau nombre est ((nouveau - ancien) / ancien) fois 100. Un résultat négatif est une diminution.

Exemple travaillé. 15% de 250 équivaut à 37,5. 45 équivaut à 25 % de 180, car 45/180 = 0,25. Passer de 80 à 100 représente une augmentation de 25%, car (100 - 80) / 80 = 0,25.

Exemples d'usage

  • Une remise : 20 % de 80 font 16, donc le prix de vente est de 64.
  • Une augmentation : De 80 à 100, c'est +25%, pas +20. La base est l'ancien numéro.

Questions fréquentes

Comment calculer le pourcentage d’augmentation ou de diminution ?

((Nouveau - Ancien) / Ancien) * 100.

Pourquoi 80 à 100 ne représente-t-il pas une augmentation de 20 % ?

Vingt équivaut à 20 % de 100, mais le changement est mesuré à partir de la valeur de départ. Vingt représente 25 % de 80.

Que se passe-t-il si le numéro de départ est 0 ?

Le changement en pourcentage est divisé par l'ancien nombre. De 0 à n’importe quel autre nombre, cette division n’est pas définie, le résultat n’est donc pas un pourcentage significatif.
