Présentation générale et mécanique algorithmique

Le calculateur de rapport d'aspect OmniTools calcule les dimensions proportionnelles de largeur et de hauteur en fonction des rapports géométriques fondamentaux et des algorithmes du plus grand diviseur commun (PGCD). Lors de la conception de sites Web réactifs, du rendu de vidéos 4K/1080p ou de la configuration de requêtes de conteneur CSS, la préservation des proportions exactes évite les changements de mise en page (Cumulative Layout Shift, CLS) et la distorsion visuelle. Notre calculateur calcule les dimensions exactes correspondantes, trouve le rapport hauteur/largeur entier le plus simple à l'aide de l'algorithme GCD d'Euclide et génère des propriétés CSS « ​​rapport hauteur/largeur » prêtes à l'emploi pour les mises en page Web modernes.

CSS et équivalents de code pour le calcul du rapport hauteur/largeur

CLI Bash/Terminal :
# Find image dimensions and aspect ratio via ImageMagick
identify -format "%w x %h\n" image.png

# Using ffprobe for video dimensions
ffprobe -v error -select_streams v:0 -show_entries stream=width,height input.mp4
Python3 :
import math

def get_aspect_ratio(width, height):
    gcd = math.gcd(width, height)
    return f"{width // gcd}:{height // gcd}"

print(get_aspect_ratio(1920, 1080)) # '16:9'
JavaScript/Node.js :
// Modern CSS aspect ratio property
/* CSS Aspect Ratio Standard */
.video-player {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}

Questions fréquentes

Qu'est-ce que la résolution 16:9 ?

16:9 est le format d’image standard pour les téléviseurs haute définition et les écrans d’ordinateurs modernes.

Comment calculer la nouvelle hauteur si je connais la largeur ?

Multipliez la nouvelle largeur par la hauteur d'origine, puis divisez par la largeur d'origine : $\text{Nouvelle hauteur} = (\text{Nouvelle largeur} \times \text{Hauteur d'origine}) / \text{Largeur d'origine}$.

Pourquoi la propriété CSS aspect-ratio est-elle meilleure que les hacks padding-bottom ?

La propriété CSS moderne « aspect-ratio » est nativement prise en charge dans tous les navigateurs modernes et élimine le besoin de wrappers de conteneurs et de hacks « padding-bottom : 56,25 % ».

Qu'est-ce que l'algorithme d'Euclide pour les proportions ?

L'algorithme d'Euclide trouve le plus grand diviseur commun (PGCD) de deux nombres en divisant à plusieurs reprises le reste jusqu'à ce qu'il atteigne zéro, réduisant ainsi les dimensions brutes comme 1920 × 1080 à leur forme fractionnaire la plus simple (16:9).
