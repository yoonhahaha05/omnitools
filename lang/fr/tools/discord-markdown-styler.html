Présentation générale et mécanique algorithmique

Discord utilise son propre Markdown. **text** est en gras, *text* en italique, __text__ est souligné, ~~text~~ est barré et ||text|| est un spoiler. Un horodatage utilise l'heure Unix en secondes : <t:1719792000:R> s'affiche sous forme d'heure relative dans la zone de chaque spectateur, <t:1719792000:F> sous forme de date complète. Les couleurs ANSI ne fonctionnent qu'à l'intérieur d'un bloc de code étiqueté ansi, en utilisant des séquences d'échappement telles que \u001b[31m pour le rouge.

Exemple travaillé. Envelopper une partition dans || || produit ||12||, sur lequel d'autres personnes doivent cliquer. L’instant du 1er juillet 2024 à 00h00 UTC est 1719792000. Le jeton relatif est <t:1719792000:R>. Un mot rouge dans un bloc ansi commence par le code SGR rouge et se termine par le code de réinitialisation.

Exemples d'usage

  • Un spoiler : ||12|| cache le score jusqu'à ce que quelqu'un clique dessus.
  • Un horodatage : t:1719792000:R, écrit entre crochets angulaires, correspond au 1er juillet 2024 à 00h00 UTC, affiché par rapport à chaque lecteur.

Fonctions

  • Marquage des spoilers (||caché||)
  • Générateur d'horodatage dynamique interactif (<t:epoch:R>)
  • Barre d'outils gras, italique, souligné, barré

Mode d'emploi

  1. Tapez votre texte de discussion ou sélectionnez des mots.
  2. Cliquez sur les boutons de formatage pour envelopper le texte.
  3. Copiez et collez dans Discord.

Questions fréquentes

Comment fonctionnent les horodatages Discord ?

Les horodatages Discord se formatent sous la forme <t:timestamp:R> et affichent automatiquement l'heure relative (« en 5 minutes ») ajustée au fuseau horaire local de chaque utilisateur.

Pourquoi les couleurs échouent-elles dans un message normal ?

Discord n'applique que les couleurs ANSI à l'intérieur d'une barrière de code dont la langue est ansi. Les audacieux et les spoilers fonctionnent en dehors de cette clôture.

Quel style d'horodatage est :t par rapport à :F ?

:t est un temps court, :T ajoute des secondes, :d est une date courte, :D une date longue, :f une date et une heure, :F une date et une heure longues et :R une phrase relative telle que « dans 2 heures ».
