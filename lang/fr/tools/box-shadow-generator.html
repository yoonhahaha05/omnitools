Présentation générale et mécanique algorithmique

Le CSS est box-shadow : x y Blur Spread Color. X et Y sont des décalages en pixels. Un X positif déplace l'ombre vers la droite. Un Y positif le fait descendre. Le flou étend le bord. La propagation agrandit ou réduit l'ombre avant le flou. Un spread négatif attire l’ombre vers l’intérieur. L'ombre ne change pas la disposition. Il peint en dehors de la zone de bordure, à moins que l'encart ne soit défini.

Exemple travaillé. box-shadow : 0 8px 24px rgba(0, 0, 0, 0.18) est une goutte douce sous une carte : pas de décalage horizontal, 8 pixels vers le bas, 24 pixels de flou, pas d'étalement, 18 % de noir. Un lifting capillaire est de 0 1px 2px rgba (0, 0, 0, 0,08). Un décalage dur, du type utilisé dans les mises en page brutalistes, est de 8px 8px 0 #111, sans flou.

Exemples d'usage

  • Une carte : 0 8px 24px rgba(0, 0, 0, 0,18).
  • Un décalage dur : 8px 8px 0 #111, avec le flou laissé à 0.

Fonctions

  • Curseurs visuels en temps réel pour le décalage X, Y, le flou et le rayon de propagation
  • Contrôle alpha/opacité des ombres personnalisé
  • Génération d'extraits de code CSS propres et prêts à coller

Mode d'emploi

  1. Faites glisser les curseurs pour ajuster l’élévation, la direction et la propagation.
  2. Observez l'aperçu de la carte rendue en temps réel.
  3. Cliquez sur "Copier CSS" pour coller la déclaration directement dans votre feuille de style.

Questions fréquentes

À quoi sert le rayon de propagation négatif dans Box-Shadow ?

Un rayon de propagation négatif réduit la taille de l'ombre vers l'intérieur, créant des effets d'éclairage subtils et réalistes qui évitent les bordures dures sous les cartes.

À quoi sert un Y négatif ?

L'ombre se trouve au-dessus de la boîte. Utilisez-le lorsque la source de lumière est en dessous de l'élément.

Puis-je empiler deux ombres ?

CSS autorise une liste séparée par des virgules. Ce générateur écrit une ombre. Collez vous-même une deuxième déclaration si vous avez besoin à la fois d'un bord serré et d'une large lueur.
