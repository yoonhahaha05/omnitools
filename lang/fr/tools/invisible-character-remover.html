Présentation générale et mécanique algorithmique

Certains caractères ne prennent aucun espace visible. U+200B est un espace de largeur nulle, U+200C non-jointeur de largeur nulle, U+200D jointeur de largeur nulle et U+FEFF est la marque d'ordre des octets. U+00A0 est un espace insécable, qui ressemble à un espace mais ne correspond pas à un espace normal dans la recherche. Les attaques Trojan Source utilisent des contrôles bidi tels que U+202E pour afficher le code dans un ordre différent de celui lu par le compilateur.

Exemple travaillé. Le mot "hel\u200Blo" ressemble à bonjour et a une longueur de 6 et non de 5. Après une bande de caractères de largeur nulle, la longueur est de 5 et une recherche de bonjour correspond. Un fichier qui commence par U+FEFF perd cette marque, ce qui est important lorsqu'un hachage ou une vérification shebang échoue sur un script par ailleurs identique.

Exemples d'usage

  • Un échec de recherche : bonjour avec un U+200B au milieu ça a l'air normal et ne correspond pas tant que la marque n'est pas supprimée.
  • Une nomenclature : U+FEFF au début d'un script est supprimé afin que le premier caractère visible soit le véritable début du fichier.

Fonctions

  • Détecte U+200B, U+200C, U+200D, U+FEFF
  • Analyse côté client complètement privée
  • Empêche l'injection de code source du cheval de Troie

Mode d'emploi

  1. Collez le texte dans le champ de saisie.
  2. Consultez le compteur de caractères invisibles.
  3. Cliquez sur Nettoyer maintenant.

Questions fréquentes

Qu’est-ce qui cause les espaces de largeur nulle ?

Copying text from rich text editors, chat applications, or PDFs often brings along hidden formatting bytes.

Cela supprimera-t-il les menuisiers emoji de couleur chair ?

U+200D est également utilisé pour joindre des emoji en un seul glyphe, comme une séquence familiale. Le dépouiller divise ces emoji.

Le comptoir comprend-il des espaces ordinaires ?

Les espaces ordinaires sont visibles. Le compteur est pour les personnages cachés et incassables, les cibles les plus propres.
