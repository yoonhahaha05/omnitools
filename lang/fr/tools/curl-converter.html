Présentation générale et mécanique algorithmique

Une commande curl de DevTools contient déjà la méthode, l'URL, les en-têtes et le corps. Cette page lit ces éléments et imprime la même requête que les requêtes fetch ou Python. Il n'envoie pas la demande.

Exemple travaillé. curl -X POST https://example.com/api -H 'Content-Type: application/json' -d '{"a":1}' devient un appel de récupération avec la méthode POST, cet en-tête et le corps '{"a":1}', plus un appel request.post avec le même en-tête et un argument json ou data. A -H 'Autorisation : Porteur …' est copié. Traitez la sortie comme un secret si la boucle que vous avez collée en contenait une.

Exemples d'usage

  • Un POST de DevTools : La méthode, l'URL, l'en-tête JSON et le corps atterrissent dans la récupération et dans les requêtes.
  • Un jeton au porteur : L'en-tête Autorisation est copié. Ne le commettez pas.

Fonctions

  • Extrait automatiquement l'URL, le verbe HTTP, les en-têtes et le corps de la demande
  • Produit du JavaScript et du Python idiomatiques
  • Copier le code en 1 clic

Mode d'emploi

  1. Collez la commande cURL à partir de Chrome DevTools ou de la documentation.
  2. Choisissez l'onglet Langue.
  3. Copiez le code dans votre projet.

Questions fréquentes

Comment puis-je obtenir cURL à partir de Chrome DevTools ?

Cliquez avec le bouton droit sur n'importe quelle demande de réseau dans l'onglet Réseau, sélectionnez Copier -> Copier en tant que cURL.

Où puis-je copier curl dans Chrome ?

DevTools, Réseau, cliquez avec le bouton droit sur la demande, Copier, Copier en tant que cURL.

Les cookies sont-ils transformés en pot à biscuits ?

Un en-tête Cookie est copié en tant qu'en-tête. La page ne crée pas de session de requêtes ni de magasin de cookies de navigateur.
