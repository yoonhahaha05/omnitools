Présentation générale et mécanique algorithmique

La note est enregistrée dans localStorage sur cette origine, sous une clé que possède la page. Chaque changement écrit le texte actuel. La fermeture de l'onglet n'efface pas localStorage. Effacer les données du site, utiliser une fenêtre privée ou ouvrir un autre profil de navigateur le fait. Le nombre de mots est le même que celui utilisé ailleurs : texte coupé, divisé en espaces. Le téléchargement écrit un fichier .txt du contenu actuel. Le texte n'est pas envoyé à un serveur.

Exemple travaillé. Une note de 1 200 caractères équivaut à quelques kilo-octets. Les navigateurs autorisent généralement environ 5 Mo pour le stockage local d'une origine, le bloc-notes est donc destiné aux notes et non à une archive de documents. Si le stockage est plein, l'écriture est lancée et la dernière modification reste uniquement à l'écran. Exportez une copie avant d’effacer les données de navigation.

Exemples d'usage

  • Un brouillon que vous rouvrirez demain : Il est toujours dans localStorage sur ce navigateur.
  • Une sauvegarde : Téléchargez le .txt. La suppression des données du site supprime la copie stockée.

Fonctions

  • Sauvegarde automatique continue dans le navigateur LocalStorage
  • 100 % privé : les notes ne sont jamais téléchargées ni synchronisées sur des serveurs externes
  • Téléchargement de fichiers en texte brut (.txt) en un clic

Mode d'emploi

  1. Tapez ou collez des notes dans le bloc-notes.
  2. Votre texte est enregistré immédiatement et automatiquement en arrière-plan.
  3. Cliquez sur « Télécharger .txt » pour exporter vos notes à tout moment.

Questions fréquentes

Mes notes disparaîtront-elles si je ferme l'onglet du navigateur ?

Non. Vos notes sont stockées dans le « localStorage » persistant de votre navigateur et se rechargeront chaque fois que vous revisiterez OmniTools.

Est-ce que cela se synchronise avec mon téléphone ?

Non, localStorage reste sur ce profil de navigateur. Déplacez le texte avec le téléchargement ou copiez-le.

Un autre site Web peut-il lire la note ?

Non. Le navigateur expose uniquement localStorage à la même origine.
