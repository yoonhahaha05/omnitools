Arquitetura de domínio e padrões de privacidade

As ferramentas de produtividade OmniTools utilizam interfaces de hardware de navegador nativas, incluindo a API de áudio da Web para síntese de áudio de metrônomo sem latência, API de criptografia da Web para geração de senha CSPRNG e API de tempo de navegação para diagnóstico de latência em tempo real.

Perguntas frequentes

Quão seguro é o Gerador de Senhas?

Ele usa o padrão criptográfico window.crypto.getRandomValues() do navegador, garantindo uma verdadeira entropia pseudoaleatória criptograficamente segura.

Onde o Scratchpad armazena minhas anotações?

As notas são armazenadas na sandbox local window.localStorage do seu navegador. Eles permanecem no seu dispositivo mesmo se você fechar a guia.
