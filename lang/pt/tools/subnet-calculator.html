Visão geral e mecânica algorítmica

Uma calculadora de máscara de sub-rede transforma um endereço como 192.168.1.10/24 no endereço de rede, no intervalo de hosts utilizável e no endereço de broadcast. A calculadora realiza cálculos de rede bit a bit em tempo real com base em RFC 1519 (Classless Inter-Domain Routing) e RFC 791 (Internet Protocol). Ao converter octetos decimais pontilhados IPv4 padrão em inteiros binários de 32 bits, a calculadora aplica operações AND bit a bit com a máscara de sub-rede para determinar o endereço base exato da rede, o endereço de transmissão e a capacidade do host. Na engenharia de nuvem moderna (AWS VPC, Google Cloud VPC, Azure VNet) e na arquitetura de rede local, a alocação precisa de sub-redes evita o esgotamento de endereços IP e conflitos de sobreposição de roteamento. A aritmética é executada no seu navegador.

Exemplo trabalhado. Pegue 192.168.1.10/24. O prefixo /24 significa que os primeiros 24 bits são a rede, portanto a máscara é 255.255.255.0. O endereço de rede é 192.168.1.0. O endereço de transmissão é 192.168.1.255. Dos 256 endereços do bloco, 254 podem ser atribuídos a hosts (192.168.1.1 a 192.168.1.254).

Exemplos de uso

  • Infraestrutura em nuvem (AWS/GCP/Azure): Planejando blocos CIDR de VPC não sobrepostos e alocações de sub-redes públicas/privadas para microsserviços multicamadas.
  • Engenharia de rede empresarial: Configurar listas de controle de acesso (ACLs) do roteador, intervalos de escopo DHCP e resumos de roteamento OSPF/BGP.
  • Orquestração DevOps e Docker: Definição de intervalos de rede de ponte e alocações de CIDR de pod do Kubernetes.

Equivalentes de terminal e código para cálculo de sub-rede

Bash/Terminal CLI:
# Calculate subnet via ipcalc
ipcalc 192.168.1.0/24

# Inspect local interface subnet
ip -o -f inet addr show
Pitão 3:
import ipaddress

net = ipaddress.ip_network('192.168.1.0/24', strict=False)
print(f'Network: {net.network_address}')
print(f'Broadcast: {net.broadcast_address}')
print(f'Usable Hosts: {net.num_addresses - 2}')
print(f'Netmask: {net.netmask}')
JavaScript/Node.js:
// Node.js IP subnet calculation via bitwise ops
function cidrToMask(bits) {
  const mask = ~(2 ** (32 - bits) - 1);
  return [24, 16, 8, 0].map(s => (mask >>> s) & 255).join('.');
}
console.log(cidrToMask(24)); // '255.255.255.0'

Recursos

  • Cálculo instantâneo de endereços de rede, transmissão e intervalo de hosts
  • Suporta todas as notações de prefixo CIDR de /1 a /32
  • Inclui máscaras curinga e classificação de IP público/privado RFC 1918
  • Cálculo bit a bit 100% do lado do cliente em execução no seu navegador

Como usar

  1. Insira qualquer endereço IPv4 no campo Endereço IP.
  2. Selecione seu prefixo CIDR (/1 a /32) no menu suspenso ou clique em uma predefinição rápida.
  3. Revise os limites da rede, o intervalo de IP utilizável e as capacidades do host.

Perguntas frequentes

Por que há menos dois hosts utilizáveis do que o total de endereços IP?

Em sub-redes IPv4 padrão (/30 e maiores), o primeiro endereço é reservado como identificador de rede e o endereço final é reservado como endereço de Broadcast.

Qual é a diferença entre uma máscara de sub-rede e uma máscara curinga?

Uma máscara curinga é o inverso exato (NÃO bit a bit) de uma máscara de sub-rede. É amplamente utilizado em listas de controle de acesso (ACLs) da Cisco e configurações de rede OSPF.

Qual é a diferença entre endereço de rede e endereço de broadcast?

O endereço de rede é o IP mais baixo da sub-rede (todos os bits de host 0) e identifica a própria sub-rede. O endereço de broadcast é o IP mais alto (todos os bits de host 1) usado para enviar pacotes a todos os hosts naquela sub-rede. Nenhum deles pode ser atribuído a interfaces de rede individuais.

Por que a AWS reserva 5 endereços IP por sub-rede em vez de 2?

A rede padrão reserva 2 endereços (rede e transmissão). A AWS reserva três endereços adicionais para o roteador VPC (.1), servidor DNS (.2) e uso futuro de serviço interno (.3).

Minha configuração de IP privado é carregada em algum lugar?

Nunca. Os cálculos são executados exclusivamente na memória do navegador por meio de operações JavaScript bit a bit. A arquitetura da sua rede interna permanece completamente segura.
