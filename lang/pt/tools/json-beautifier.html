Visão geral e mecânica algorítmica

O Embelezador, Validador e Formatador JSON do OmniTools analisa documentos JSON brutos de acordo com as especificações RFC 8259. Ele constrói uma representação de sintaxe abstrata na memória do cliente, normaliza escapes de string, detecta erros de sintaxe estrutural (como chaves sem aspas, vírgulas finais ou colchetes ausentes) e serializa novamente os dados com 2 espaços configuráveis, 4 espaços ou recuo de tabulação. O formatador usa JSON.parse e JSON.stringify do navegador. Ele não aceita comentários, chaves entre aspas simples ou vírgulas finais, porque esses não são JSON válidos.

Exemplo trabalhado. Cole {"name":"Ada","ok":true} e escolha o recuo de 2 espaços. O resultado é:

{ "nome": "Ada", "ok": verdadeiro }

Uma vírgula final, como em {"name":"Ada",}, é rejeitada. Remova a vírgula e formate novamente.

Exemplos de uso

  • Depuração de API e inspeção de carga útil: Formatação de cargas JSON REST e GraphQL minificadas ilegíveis retornadas de servidores de produção.
  • Validação do arquivo de configuração: Limpeza e linting de arquivos de configuração complexos (package.json, tsconfig.json, Kubernetes ConfigMaps).
  • Saneamento e minificação de dados: Removendo espaços em branco e retornos de carro desnecessários para otimizar os tamanhos de transferência de carga útil.

Equivalentes de terminal e código para formatação JSON

Bash/Terminal CLI:
# Pretty print JSON using jq
cat data.json | jq .

# Format JSON using Python CLI
python3 -m json.tool data.json
Pitão 3:
import json

raw = '{"name":"omnitools","status":200}'
parsed = json.loads(raw)
print(json.dumps(parsed, indent=2, sort_keys=True))
JavaScript/Node.js:
// JavaScript native JSON formatting
const raw = '{"tool":"json-beautifier","local":true}';
const formatted = JSON.stringify(JSON.parse(raw), null, 2);
console.log(formatted);

Perguntas frequentes

As vírgulas finais são válidas em JSON?

Não, a especificação JSON padrão proíbe vírgulas finais.

Por que o JSON proíbe vírgulas finais?

A RFC 8259 proíbe estritamente vírgulas finais para garantir uma análise inequívoca em todas as linguagens de programação e analisadores legados mais antigos.

O OmniTools pode formatar arquivos JSON enormes sem travar?

Sim. Como as operações são executadas diretamente na memória local do navegador, sem intervalos de rede, você pode formatar confortavelmente arquivos de até dezenas de megabytes, dependendo da RAM disponível.

O OmniTools oferece suporte a JSON5 ou JSON com comentários?

O JSON padrão proíbe estritamente comentários (// ou /* */). Nosso formatador segue o padrão oficial RFC 8259 para garantir que a saída seja válida em todos os analisadores de produção.
