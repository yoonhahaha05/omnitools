Visão geral e mecânica algorítmica

O minificador remove comentários CSS e reduz os espaços em branco em torno da pontuação. Seletores, propriedades e valores permanecem. Ele não renomeia classes, mescla regras duplicadas ou elimina prefixos de fornecedores. Um comentário dentro de uma string não é um comentário.

Exemplo trabalhado. Uma regra escrita como .card { color: #111; /* título */ margem: 0; } minimiza em direção a .card{color:#111;margin:0}. A contagem de declarações não muda. Um bloco @media (largura mínima: 600px) permanece válido porque o espaço dentro da consulta não é necessário entre cada token e os parênteses são preservados. A porcentagem de compactação é (bytes originais - bytes reduzidos)/bytes originais.

Exemplos de uso

  • Uma regra de cartão: Comentários e espaços extras são eliminados. cor e margem permanecem.
  • Uma consulta de mídia: A condição permanece. O bloco não é excluído.

Recursos

  • Limpa comentários bloqueados
  • Recolhe espaços desnecessários em torno da sintaxe CSS
  • Mostra estatísticas de compactação

Como usar

  1. Cole o código bruto da folha de estilo CSS.
  2. Clique em Minificar CSS.
  3. Copie a saída.

Perguntas frequentes

A minificação interromperá as consultas de mídia?

Não, o espaçamento de sintaxe padrão nas consultas @media é preservado.

Isso quebrará uma expressão calc()?

Os espaços exigidos pelo CSS, como os espaços ao redor de + e - dentro de calc(), são os que devem ser mantidos. O minificador reduz os espaços em branco que a gramática não precisa.

Os mapas de origem são produzidos?

Não. Você obtém apenas o texto reduzido.
