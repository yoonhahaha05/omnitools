Visão geral e mecânica algorítmica

Um comando curl do DevTools já contém o método, URL, cabeçalhos e corpo. Esta página lê essas partes e imprime a mesma solicitação que fetch ou como solicitações Python. Não envia a solicitação.

Exemplo trabalhado. curl -X POST https://example.com/api -H 'Content-Type: application/json' -d '{"a":1}' torna-se uma chamada de busca com o método POST, aquele cabeçalho e corpo '{"a":1}', além de uma chamada requests.post com o mesmo cabeçalho e um json ou argumento de dados. A -H 'Autorização: Portador…' é copiado. Trate a saída como um segredo se o curl que você colou contiver um.

Exemplos de uso

  • UMA POSTAGEM do DevTools: método, URL, cabeçalho JSON e corpo aparecem na busca e nas solicitações.
  • Um token ao portador: O cabeçalho de autorização é copiado. Não cometa isso.

Recursos

  • Extrai URL, verbo HTTP, cabeçalhos e corpo da solicitação automaticamente
  • Produz JavaScript idiomático e Python
  • Copiar código com 1 clique

Como usar

  1. Cole o comando cURL do Chrome DevTools ou da documentação.
  2. Escolha a guia de idioma.
  3. Copie o código em seu projeto.

Perguntas frequentes

Como obtenho cURL do Chrome DevTools?

Clique com o botão direito em qualquer solicitação de rede na guia Rede, selecione Copiar -> Copiar como cURL.

Onde copio curl no Chrome?

DevTools, Rede, clique com o botão direito na solicitação, Copiar, Copiar como cURL.

Os biscoitos são transformados em potes de biscoitos?

Um cabeçalho de cookie é copiado como cabeçalho. A página não cria uma sessão de solicitações ou armazenamento de cookies do navegador.
