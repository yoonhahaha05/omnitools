Sobre OmniTools

Um site utilitário gratuito da Web no dispositivo para engenheiros de software, escritores e analistas.

Por que o OmniTools existe

A web moderna está repleta de sites utilitários que deveriam ser simples, mas não são. A maioria dos formatadores JSON on-line, decodificadores Base64, testadores de regex e calculadoras de sub-rede forçam os usuários a fazer viagens de ida e volta no servidor, paredes de cookies intrusivas, captchas e anúncios pop-up. Pior ainda, colar tokens de API confidenciais, variáveis ​​de ambiente, registros de clientes ou senhas internas em um servidor de terceiros desconhecido cria sérios riscos de conformidade e segurança.

OmniTools foi criado para provar que existe uma maneira melhor. Ao aproveitar as APIs da Web de navegadores contemporâneos, incluindo a API nativa de criptografia da Web, Web Workers, HTML5 Canvas e a API de internacionalização, todos os cálculos, rotinas de formatação e hash criptográfico são executados dentro da memória do seu dispositivo. A publicidade é separada: depois de aceitar cookies, o Google AdSense pode definir cookies para exibir anúncios. Esses cookies não são informações da sua ferramenta.

Quem publica este site

OmniTools é um site independente. Não é uma empresa. O editor é o mantenedor do repositório público github.com/yoonhahaha05/omnitools (conta GitHub yoonhahaha05).

Perguntas e relatórios de bugs vão para support@getomnitools.com ou um Problema no GitHub. Ambos chegam ao mantenedor.

Arquitetura Técnica e Princípios Básicos

Entrada de ferramenta no dispositivo

Texto, arquivos, tokens e cálculos permanecem no navegador. OmniTools não executa suas próprias análises. Os anúncios usam cookies somente depois que você os aceita.

Latência zero e saída instantânea

Sem handshakes de solicitação HTTP, inicializações a frio do servidor ou consultas de banco de dados, as operações são concluídas na velocidade da CPU bare-metal em quadros abaixo de um milissegundo.

Aplicativo da Web progressivo (primeiro off-line)

OmniTools é totalmente armazenado em cache do service-worker. Você pode instalá-lo no macOS, Windows, iOS ou Android, desconectar-se do Wi-Fi e trabalhar ininterruptamente em vôo ou em ambientes remotos.

RFC aberta e padrões da Web

As calculadoras estão em estrita conformidade com os padrões internacionais: RFC 8259 (JSON), RFC 2104 (HMAC), RFC 4122 (UUID v4), RFC 4648 (Base64) e equações de contraste WCAG 2.1 AA.

Como verificar para onde vai sua entrada

Você pode confirmar se a entrada da ferramenta permanece no navegador:

1

Abra o Chrome, Firefox, Safari ou Edge e pressione F12 (ou Cmd + Opção + I) para iniciar as ferramentas do desenvolvedor.

2

Navegue até o Network guia e selecione o Fetch/XHR filtro para monitorar cargas de rede em tempo real.

3

Digite, cole tokens ou formate JSON. As ações da ferramenta não enviam essa entrada para um servidor OmniTools. Se você aceitou anúncios, verá solicitações para os domínios de anúncios do Google. Essas solicitações são os anúncios, não o seu documento.

Nosso compromisso de engenharia

OmniTools é mantido em público. Se um resultado parecer errado, relate-o no página de contato ou em um Problema no GitHub.
