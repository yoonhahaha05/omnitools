Domain-Architektur und Datenschutzstandards

Die Produktivitätstools von OmniTools nutzen native Browser-Hardwareschnittstellen, darunter die Web Audio API für latenzfreie Metronom-Audiosynthese, die Web Cryptography API für die CSPRNG-Passphrase-Generierung und die Navigation Timing API für Echtzeit-Latenzdiagnose.

Häufige Fragen

Wie sicher ist der Passwortgenerator?

Es verwendet den kryptografischen window.crypto.getRandomValues()-Standard des Browsers und gewährleistet so eine echte kryptografisch sichere pseudozufällige Entropie.

Wo speichert das Scratchpad meine Notizen?

Notizen werden in der lokalen window.localStorage-Sandbox Ihres Browsers gespeichert. Sie bleiben auf Ihrem Gerät, auch wenn Sie den Tab schließen.
