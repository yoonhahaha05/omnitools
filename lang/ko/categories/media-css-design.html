미디어, CSS 생성기 및 디자인 유틸리티

고성능 CSS 생성기, 색상 도구 및 브라우저 내 이미지 처리 유틸리티. 클립 경로 다각형, 상자 그림자, 그라디언트 및 유리 형태 스타일을 생성하고, WCAG 2.1 색상 대비를 확인하고, HTML5 Canvas를 통해 직접 이미지 크기를 조정하거나 자릅니다.

사용 가능한 미디어, CSS 및 디자인 도구

16개 유틸리티

색상 변환 (HEX, RGB, HSL)

색상을 선택하거나 16진수 코드를 붙여넣으세요. Hex, RGB 및 HSL은 동기화 상태를 유지합니다.

색상 팔레트 생성기

함께 작동하는 5가지 색상을 생성합니다. 보관하고 싶은 항목을 잠그세요.

색 대비 검사

텍스트 색상과 배경을 선택합니다. WCAG를 통과하는지 확인합니다.

QR 코드 생성기

URL을 붙여넣으세요. 코드를 다운로드하세요.

바코드 생성기

코드를 입력하세요. 바코드를 다운로드하세요.

CSS 그림자 생성기

슬라이더를 이동합니다. 상자 그림자 선을 복사합니다.

CSS 모서리 생성기

슬라이더를 이동합니다. 테두리 반경을 복사합니다.

CSS 그라데이션 생성기

색상을 선택하세요. 그라데이션 선을 복사합니다.

글래스모피즘 생성기

흐림 및 투명도를 설정합니다. CSS를 복사하세요.

SVG 경로 보기

경로를 붙여넣습니다. 모양이 보입니다.

이미지 크기 조절

사진을 삭제하세요. 크기를 설정하고 다운로드 받으세요. 파일은 이 장치에 유지됩니다.

이미지 자르기

이미지를 삭제하세요. 프레임을 선택하고 다운로드하세요. 파일은 이 장치에 유지됩니다.

이미지 필터·흑백

이미지를 삭제하세요. 필터를 적용하고 다운로드 받으세요. 파일은 이 장치에 유지됩니다.

파비콘 생성기

문자를 입력하거나 모양을 선택하세요. 사이트에 필요한 크기를 다운로드하세요.

인용 카드 만들기

견적을 입력하세요. 이미지를 다운로드하세요.

CSS clip-path 생성기

점을 드래그하세요. 클립 경로를 복사하세요.
광고

도메인 아키텍처 및 개인 정보 보호 표준

시각적 스타일 도구는 브라우저 간 호환성이 좋지 않은 경우가 많습니다. OmniTools는 CSS 변수, Flexbox, 그리드 및 최신 색상 공간을 활용하여 깔끔하고 표준을 준수하는 CSS3 코드를 생성합니다. 브라우저 내 이미지 처리는 클라우드 업로드 없이 HTML5 Canvas 2D 컨텍스트를 통해 실행됩니다.

관리 사양 및 RFC 표준

W3C CSS 박스 모델 모듈 레벨 3W3C CSS 색상 모듈 레벨 4WCAG 2.1 명암비 표준(1.4.3 및 1.4.6)HTML5 Canvas 2D 컨텍스트 사양

자주 묻는 질문

크기를 조정하거나 자를 때 내 이미지가 클라우드 서버에 업로드됩니까?

아니요. 이미지는 브라우저의 HTML5 Canvas 메모리에서 직접 렌더링되고 수정됩니다. 귀하의 사진은 절대 귀하의 장치를 떠나지 않습니다.

생성된 CSS 스타일이 최신 브라우저와 호환됩니까?

예, 모든 CSS 스니펫은 Flexbox, CSS 그리드, CSS 변수 및 크로스 브라우저 접두어를 포함한 최신 웹 표준에 최적화되어 있습니다.
