텍스트 및 서식 유틸리티

작가, 프로그래머, 콘텐츠 제작자를 위한 고속 클라이언트측 텍스트 도구입니다. 공백을 제거하고, 대소문자를 변환하고, 마크다운을 검사하고, HTML 태그를 제거하고, 텍스트를 비교하고, 브라우저에 데이터가 전혀 없는 형식의 사본을 만드세요.

Categories: 텍스트 및 서식 (25) 개발자 및 데이터 (28) 일상적인 수학 및 변환기 (25) 미디어, CSS 및 디자인 (16) 빠른 유틸리티 및 생활 도구 (11)

사용 가능한 텍스트 및 서식 도구

유틸리티 25개

글자수 세기

에세이, 캡션, 메시지를 붙여넣으세요. 입력하면 개수가 업데이트됩니다.

읽기 시간 계산기

텍스트를 붙여넣으세요. 독서 시간, 말하기 시간, 훑어보기 시간을 갖습니다.

대소문자 변환기

텍스트를 붙여넣고 대문자, 소문자, 제목 케이스 또는 CamelCase를 선택합니다.

공백 정리

지저분한 텍스트를 붙여 넣습니다. 여분의 공백과 탭이 나옵니다.

줄바꿈 제거

끊어진 줄을 붙여 넣으세요. 그들은 하나의 텍스트 블록으로 결합됩니다.

줄 정렬 (가나다·알파벳)

한 줄에 하나의 항목을 붙여넣습니다. A에서 Z로, Z에서 A로 또는 숫자별로 정렬합니다.

텍스트 뒤집기

붙여넣으세요. 문자, 단어 또는 줄 순서를 뒤집습니다.

텍스트 비교

이전 버전과 새 버전을 붙여넣으세요. 추가 및 삭제가 나란히 표시됩니다.

중복 줄 제거

목록을 붙여넣으세요. 중복된 줄이 나오고 나머지는 순서대로 유지됩니다.

마크다운 미리보기

마크다운을 입력하세요. 포맷된 페이지가 옆에 표시됩니다.

로렘 입숨 생성기

단락이나 문장 수를 선택하세요. 자리 표시자 텍스트를 복사합니다.

URL 슬러그 생성기

제목을 붙여넣으세요. 링크에 넣을 수 있는 깨끗한 슬러그를 얻습니다.

정규식 찾아 바꾸기

텍스트와 패턴을 붙여넣으세요. 일치하는 것이 무엇인지 확인한 다음 교체하십시오.

HTML 태그 제거

마크업을 붙여넣습니다. 태그는 벗겨지고 단어는 그대로 유지됩니다.

디스코드 마크다운

메시지를 입력하세요. 보내기 전에 스포일러, 코드 및 색상을 미리 볼 수 있습니다.

보이지 않는 문자 제거

붙여넣으세요. 보이지 않는 공백과 너비가 0인 문자는 제거됩니다.

텍스트·2진수 변환

단어를 입력하거나 바이너리를 붙여넣으세요. 양방향으로 변환됩니다.

텍스트·16진수 변환

단어를 입력하거나 16진수를 붙여넣으세요. 양방향으로 변환됩니다.

NATO 음성 알파벳

문자를 입력하세요. 알파, 브라보, 찰리를 얻습니다.

모스 부호 번역

메시지를 입력하거나 점과 대시를 입력하세요. 소리를 재생할 수 있습니다.

유니코드 꾸밈 글꼴

단어를 입력하세요. 굵은체, 필기체 또는 고딕체 버전을 복사하세요.

줄 번호 매기기

목록을 붙여넣으세요. 각 줄에는 숫자가 있습니다.

텍스트에서 URL 추출

이메일, 문서, 메모를 붙여넣으세요. 모든 링크는 목록으로 나타납니다.

텍스트에서 이메일 추출

메시지를 붙여넣으세요. 모든 주소가 목록으로 나타납니다.

이모지 제거

텍스트를 붙여넣으세요. 이모티콘은 나오고 단어는 그대로 유지됩니다.
광고

도메인 아키텍처 및 개인 정보 보호 표준

대용량 문서, 마크다운 사본, 코드 차이를 처리하려면 전송 대기 시간이 없는 고성능 텍스트 조작이 필요합니다. OmniTools는 V8 문자열 최적화 및 유니코드 호환 정규식(RegExp u-flag)을 활용하여 시스템 메모리를 소모하지 않고 밀리초 미만의 프레임에서 수십만 단어로 구성된 문서를 처리합니다.

관리 사양 및 RFC 표준

유니코드 표준 부록 #29(텍스트 분할)CommonMark 마크다운 사양RFC 3986(URI 백분율 인코딩)WCAG 2.1 읽기 수준 표준

자주 묻는 질문

내 텍스트 데이터가 저장되거나 원격 서버로 전송됩니까?

입력한 텍스트는 OmniTools 서버에 업로드되지 않습니다. 광고 쿠키는 귀하가 수락한 경우에만 로드됩니다.

인터넷에 연결하지 않고도 이러한 텍스트 서식 지정 도구를 사용할 수 있나요?

예! OmniTools는 전체 오프라인 캐싱을 갖춘 PWA(Progressive Web App)입니다. 로드되면 모든 텍스트 작업이 오프라인에서 원활하게 작동합니다.

텍스트 처리에 문자 또는 파일 크기 제한이 있습니까?

계산은 브라우저 메모리 내부에서 로컬로 이루어지기 때문에 API 시간 초과 없이 수십만 단어로 구성된 문서를 편안하게 처리할 수 있습니다.
