도메인 아키텍처 및 개인 정보 보호 표준

OmniTools 생산성 도구는 대기 시간 없는 메트로놈 오디오 합성을 위한 웹 오디오 API, CSPRNG 암호 생성을 위한 웹 암호화 API, 실시간 대기 시간 진단을 위한 Navigation Timing API를 포함한 기본 브라우저 하드웨어 인터페이스를 활용합니다.

관리 사양 및 RFC 표준

W3C 웹 암호화 API(CSPRNG)W3C 웹 오디오 API 사양W3C 고해상도 시간 레벨 3RFC 4086 무작위성 요구 사항

자주 묻는 질문

비밀번호 생성기는 얼마나 안전합니까?

이는 브라우저의 암호화 window.crypto.getRandomValues() 표준을 사용하여 진정한 암호화 보안 의사 난수 엔트로피를 보장합니다.

스크래치패드는 내 노트를 어디에 저장하나요?

메모는 브라우저의 로컬 window.localStorage 샌드박스에 저장됩니다. 탭을 닫아도 기기에 남아 있습니다.
