OmniTools 소개

소프트웨어 엔지니어, 작가 및 분석가를 위한 무료 온디바이스 웹 유틸리티 사이트입니다.

OmniTools가 존재하는 이유

현대 웹은 단순해야 하지만 그렇지 않은 유틸리티 웹사이트로 가득 차 있습니다. 대부분의 온라인 JSON 포맷터, Base64 디코더, 정규식 테스터 및 서브넷 계산기는 사용자에게 비대한 서버 측 왕복 여행, 방해가 되는 쿠키 벽, 보안 문자 및 팝업 광고를 강요합니다. 더 나쁜 것은 기밀 API 토큰, 환경 변수, 고객 기록 또는 내부 비밀번호를 익숙하지 않은 타사 서버에 붙여 넣으면 심각한 규정 준수 및 보안 위험이 발생한다는 것입니다.

OmniTools는 더 나은 방법이 있다는 것을 증명하기 위해 만들어졌습니다. 기본 Web Cryptography API, Web Workers, HTML5 Canvas 및 Internationalization API를 포함한 최신 브라우저 웹 API를 활용하여 모든 계산, 형식 지정 루틴 및 암호화 해시가 장치 메모리 내에서 실행됩니다. 광고는 별개입니다. 귀하가 쿠키를 수락하면 Google 애드센스에서 광고를 표시하기 위해 쿠키를 설정할 수 있습니다. 해당 쿠키는 귀하의 도구 입력이 아닙니다.

이 사이트를 게시하는 사람

OmniTools는 독립적인 웹사이트입니다. 회사가 아닙니다. 게시자는 공개 저장소의 관리자입니다. github.com/yoonhahaha05/omnitools (GitHub 계정 yoonhahaha05).

질문과 버그 신고는 다음으로 이동하세요. support@getomnitools.com 또는 GitHub 문제. 둘 다 관리자에게 도달합니다.

기술 아키텍처 및 핵심 원칙

기기 내 도구 입력

텍스트, 파일, 토큰 및 계산은 브라우저에 유지됩니다. OmniTools는 자체 분석을 실행하지 않습니다. 광고는 귀하가 쿠키를 수락한 후에만 쿠키를 사용합니다.

제로 레이턴시 및 즉시 출력

HTTP 요청 핸드셰이크, 서버 콜드 스타트 또는 데이터베이스 쿼리가 없으면 밀리초 미만의 프레임에서 베어 메탈 CPU 속도로 작업이 완료됩니다.

프로그레시브 웹 앱(오프라인 우선)

OmniTools는 완전히 서비스 워커 캐시됩니다. macOS, Windows, iOS 또는 Android에 설치하고 Wi-Fi 연결을 끊고 비행 중이거나 원격 환경에서 중단 없이 작업할 수 있습니다.

개방형 RFC 및 웹 표준

계산기는 RFC 8259(JSON), RFC 2104(HMAC), RFC 4122(UUID v4), RFC 4648(Base64) 및 WCAG 2.1 AA 대비 방정식과 같은 국제 표준을 엄격하게 준수합니다.

입력이 어디로 가는지 확인하는 방법

도구 입력이 브라우저에 유지되는지 확인할 수 있습니다.

1

Chrome, Firefox, Safari 또는 Edge를 열고 다음을 누릅니다. F12 (또는 Cmd + 옵션 + I) 개발자 도구를 실행합니다.

2

다음으로 이동하세요. Network 탭을 선택하고 Fetch/XHR 실시간 네트워크 페이로드를 모니터링하는 필터입니다.

3

토큰을 입력하거나 붙여넣거나 JSON 형식을 지정하세요. 도구 작업은 해당 입력을 OmniTools 서버로 보내지 않습니다. 광고를 수락하면 Google 광고 도메인에 대한 요청이 표시됩니다. 이러한 요청은 문서가 아니라 광고입니다.
