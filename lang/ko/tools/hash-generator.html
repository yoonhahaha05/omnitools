해시 생성기

개요 및 알고리즘 메커니즘

해시는 바이트를 고정 다이제스트에 매핑합니다. SHA-256은 32바이트이며 64개의 16진수 문자로 인쇄됩니다. SHA-512는 64바이트, 128개의 16진수 문자입니다. SHA-1은 20바이트, 40개의 16진수 문자입니다. MD5는 16바이트, 32개의 16진수 문자입니다. 동일한 입력은 항상 동일한 다이제스트를 생성합니다. 1비트 변경은 다른 다이제스트를 생성합니다. 이는 암호화되지 않습니다. 다이제스트를 다시 텍스트로 바꿀 수 없습니다.

작업된 예입니다. hello의 UTF-8 바이트는 SHA-256 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824입니다. 빈 문자열은 e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855입니다. 후행 공백이 있는 hello는 다른 다이제스트입니다. 호환성 확인을 위해 SHA-1 및 MD5가 표시됩니다. 새 비밀번호나 서명에는 사용하지 마세요.

사용 예

  • hello: SHA-256은 2cf24dba5fb0a30e를 시작합니다.
  • 빈 문자열: SHA-256은 e3b0c44298fc1c14를 시작합니다.

기능

  • 웹 암호화 미묘한 다이제스트를 통해 하드웨어 가속화
  • 원격 서버로 데이터 전송 없음
  • 여러 알고리즘을 동시에 계산합니다.

사용 방법

  1. 입력 상자에 문자열을 입력합니다.
  2. 해시는 자동으로 계산됩니다.
  3. 원하는 해시 옆에 있는 복사를 클릭하세요.

자주 묻는 질문

SHA-256이란 무엇입니까?

SHA-256은 고유한 64자 16진수 다이제스트를 생성하는 업계 표준 256비트 암호화 해시 함수입니다.

파일을 해시합니까?

입력한 텍스트를 UTF-8로 해시합니다. 디스크에서 파일을 읽지 않습니다.

일치하는 SHA-256이 텍스트가 안전하다는 증거입니까?

이는 바이트가 이미 신뢰하는 다이제스트와 일치한다는 것만 증명합니다. 내용이 옳다거나 선량하다는 뜻은 아닙니다.
