개요 및 알고리즘 메커니즘

Unix 타임스탬프는 1970-01-01 00:00:00 UTC 이후의 초를 계산합니다. 그 순간을 에포크(epoch)라고 합니다. 10자리 숫자는 초입니다. 13자리 숫자는 밀리초입니다. 이 변환기는 10,000,000,000 미만의 값을 초로 처리하고 날짜를 작성하기 전에 여기에 1,000을 곱합니다. 더 큰 값은 이미 밀리초입니다.

페이지에는 UTC와 사용 중인 컴퓨터의 시간대로 동일한 순간이 표시됩니다.

작업된 예입니다. 1700000000은 10자리이므로 초입니다. 2023-11-14 22:13:20 UTC입니다. 컴퓨터가 한국 표준시(UTC+9)로 설정된 경우 로컬 회선은 Wed Nov 15 2023 07:13:20 GMT+0900으로 표시됩니다.

사용 예

  • 로그 라인: 서버 로그에는 1700000000이 저장됩니다. 직접 초를 계산하는 대신 UTC 시간을 보려면 붙여넣으세요.
  • API 필드: JSON은 종종 Create_at를 초로 저장합니다. 숫자가 13자리이면 이미 밀리초이므로 다시 1,000을 곱하면 안 됩니다.

기능

  • 활성 실시간 라이브 에포크 티커
  • 초 대 밀리초 자동 감지
  • UTC 및 지역 오프셋

사용 방법

  1. 날짜를 디코딩하려면 Unix 타임스탬프를 붙여넣으세요.
  2. 현재 에포크 타임스탬프를 복사합니다.

자주 묻는 질문

에포크 시간이란 무엇입니까?

에포크 시간은 1970년 1월 1일 UTC 이후 경과된 초 수입니다.

일부 타임스탬프의 숫자가 13자리인 이유는 무엇입니까?

JavaScript Date.now()는 밀리초를 반환합니다. 대부분의 데이터베이스와 Python의 time.time()에서 Unix 시간은 초입니다. 10자리는 초를 의미합니다. 13자리는 밀리초를 의미합니다.

변환기가 내 시계를 변경합니까?

아니요. 붙여넣은 타임스탬프만 읽고 브라우저의 날짜 개체로 형식을 지정합니다.
