개요 및 알고리즘 메커니즘

왼쪽 창은 Markdown 소스입니다. 오른쪽 창은 렌더링하는 HTML입니다. 제목, 목록, 링크, 강조 및 분리된 코드 블록은 일반적인 CommonMark 스타일 매핑을 따릅니다. HTML을 복사하면 조각이 제공됩니다. 다운로드는 자체적으로 열 수 있는 작은 HTML 파일을 작성합니다.

작업된 예입니다. 소스 "# Notes\n\n- alpha\n- beta"는 h1과 두 개의 li 요소가 있는 ul로 렌더링됩니다. js로 표시된 울타리 블록은 코드 블록으로 유지됩니다. 실행되지 않습니다. 인라인 링크 [OmniTools](https://getomnitools.com/)는 해당 href의 앵커가 됩니다.

사용 예

  • 짧은 메모: "# Notes"와 두 개의 목록 항목이 h1 및 ul이 됩니다.
  • README 확인: Markdown을 커밋하기 전에 HTML 조각을 복사하여 태그를 확인하세요.

기능

  • 라이브 인스턴트 렌더링 분할 보기
  • 전체 HTML 웹페이지 파일 또는 원시 HTML 마크업 문자열을 내보냅니다.
  • 종속성 없음

사용 방법

  1. 왼쪽 창에서 Markdown 문서의 초안을 작성합니다.
  2. 오른쪽 미리보기 창에서 라이브 렌더링된 출력을 검사합니다.
  3. 완료되면 'HTML 복사' 또는 '.html 다운로드'를 클릭하세요.

자주 묻는 질문

마크다운이란 무엇입니까?

마크다운은 HTML로 변환되는 깔끔한 형식을 위해 설계된 경량 마크업 언어입니다.

Markdown의 원시 HTML 태그가 렌더링됩니까?

미리보기에는 서식이 지정된 문서가 표시됩니다. 내보낸 마크업을 사이트에서 재사용하려는 경우 신뢰할 수 없는 HTML을 붙여넣지 마십시오.

분리된 코드 블록이 실행되나요?

아니요. 코드로 표시됩니다.
