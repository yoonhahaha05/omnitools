개요 및 알고리즘 메커니즘

각 버튼은 동일한 문자열을 다른 단어 경계로 다시 작성합니다. 공백, 하이픈 및 밑줄은 구분 기호로 처리됩니다. camelCase 및 PascalCase는 구분 기호를 삭제하고 다음 단어를 대문자로 표시합니다. snake_case 및 kebab-case는 모두 소문자로 표시하고 _ 또는 -로 연결합니다.

작업된 예입니다. 입력된 "사용자 로그인 횟수"는 USER LOGIN COUNT, 사용자 로그인 횟수, 사용자 로그인 횟수, userLoginCount, UserLoginCount, user_login_count, user-login-count가 됩니다. 반대로 말하면, 소문자 뒤에 대문자가 오는 것은 단어 분리이므로 userLoginCount는 user_login_count가 됩니다. 연속된 대문자는 함께 유지됩니다. XMLHttpRequest는 xml_http_request가 아닌 xmlhttp_request가 됩니다.

기술 사양

입력Case결과
사용자 로그인 횟수camelCaseuserLoginCount
사용자 로그인 횟수PascalCaseUserLoginCount
사용자 로그인 횟수snake_caseuser_login_count
사용자 로그인 횟수kebab-caseuser-login-count
사용자 로그인 횟수제목 케이스사용자 로그인 수

사용 예

  • JSON 키: "사용자 로그인 횟수"는 userLoginCount 또는 user_login_count가 됩니다.
  • URL 조각: kebab-case에서는 동일한 문구가 user-login-count가 됩니다.

기능

  • 표준 프로그래밍 규칙 지원(camelCase, snake_case, kebab-case, PascalCase)
  • 자연어 케이스 처리(제목 케이스, 문장 케이스, 대문자, 소문자)
  • 원클릭으로 클립보드에 복사

사용 방법

  1. 변환기 입력에 텍스트를 입력하거나 붙여넣습니다.
  2. 원하는 케이스 형식 버튼을 클릭하세요.
  3. 한 번의 클릭으로 결과를 복사합니다.

자주 묻는 질문

카멜케이스란 무엇인가요?

CamelCase에서는 단어가 공백 없이 결합되며 첫 번째 단어를 제외한 모든 단어는 대문자로 시작됩니다.

CamelCase가 XMLHttpRequest를 분할합니까?

단어가 이미 공백, 하이픈 또는 밑줄로 구분된 경우에만 해당됩니다. 단일 토큰의 내부 대문자는 함께 남습니다.

숫자는 어떻게 되나요?

숫자는 공백으로 구분될 때 그 자체의 단어입니다. "http 2 클라이언트"는 camelCase에서는 http2Client가 되고 snake_case에서는 http_2_client가 됩니다.
