개요 및 알고리즘 메커니즘

12px와 같은 단일 반경은 모든 모서리를 동일하게 둥글게 만듭니다. 8개 값 형식이 더 구체적입니다. 슬래시 앞에는 네 가지 값이 왼쪽 위, 오른쪽 위, 오른쪽 아래 및 왼쪽 아래 모서리의 수평 반경을 설정합니다. 슬래시 뒤에는 4개의 값이 동일한 순서로 수직 반경을 설정합니다. 모서리의 두 반경이 다른 경우 모서리는 1/4 타원이 되며, 이것이 얼룩이 만들어지는 방식입니다.

작업된 예입니다. border-radius: 60% 40% 30% 70% / 50% 60% 30% 40% 각 모서리를 다르게 스쿼시하고 유기적 얼룩으로 읽습니다. border-radius: 999px는 높이가 고정된 버튼에 알약 모양을 만듭니다. 반경이 높이의 절반보다 크고 CSS가 이를 고정하기 때문입니다. 정사각형 요소의 50%는 원을 만듭니다.

사용 예

  • 알약 버튼: border-radius: 짧고 넓은 버튼의 경우 999px.
  • 서클 아바타: border-radius: 정사각형 이미지의 50%.

기능

  • 전체 8축 테두리 반경 슬라이더 컨트롤
  • 즉각적인 무작위 유기 얼룩 모양 생성기
  • 즉시 사용 가능한 CSS 테두리 반경 코드 조각

사용 방법

  1. 수평 및 수직 백분율 슬라이더를 조정합니다.
  2. 창의적인 영감을 얻으려면 'Random Organic Blob'을 클릭하세요.
  3. CSS 규칙을 랜딩 페이지나 UI 디자인에 복사하세요.

자주 묻는 질문

border-radius의 슬래시는 어떻게 작동하나요?

슬래시 앞의 값은 4개 모서리의 수평 반경을 정의하고, 슬래시 뒤의 값은 수직 반경을 정의합니다. 이를 통해 비대칭 유체 방울 모양을 만들 수 있습니다.

50%는 왜 원처럼 보이지 않나요?

50%는 요소 자체의 너비와 높이를 따릅니다. 직사각형에서는 타원이 됩니다. 상자는 정사각형이어야 합니다.

슬래시는 무엇을 구분합니까?

슬래시 앞의 수평 반경, 슬래시 뒤의 수직 반경.
