개요 및 알고리즘 메커니즘

뷰포트는 CSS 픽셀 단위의 브라우저 레이아웃 창이며 크기를 조정하면 변경됩니다. 화면 크기는 디스플레이이며 CSS 픽셀로도 보고됩니다. 장치 픽셀 비율은 CSS 픽셀당 물리적 ​​픽셀입니다. 비율이 2라는 것은 1440 너비 레이아웃 뷰포트의 너비가 2880 장치 픽셀임을 의미하며 이는 일반적인 Retina 사례입니다. 중단점 라벨은 너비를 일반적인 Tailwind 경계(sm 640, md 768, lg 1024, xl 1280, 2xl 1536)와 일치시킵니다.

작업된 예입니다. 최대화된 창이 있는 DPR 2의 랩톱은 1440×800 근처의 뷰포트, 1440×900의 화면 및 DPR 2를 표시할 수 있습니다. 창을 700픽셀로 좁히면 중단점 레이블이 sm으로 이동합니다. 700은 최소 640이고 768 미만이기 때문입니다. 색상 심도는 screen.colorDepth 값으로, 대개 24입니다. 터치는 브라우저가 터치 스크린을 보고하는지 여부를 나타냅니다. 터치 패널이 있는 노트북에서는 마우스를 사용하는 경우에도 마찬가지입니다.

사용 예

  • Retina 노트북: DPR 2. 1440 CSS 픽셀 너비는 2880 실제 픽셀입니다.
  • 반응형 검사: 768과 1024를 가로질러 창을 드래그하고 중단점 레이블이 변경되는 것을 확인하세요.

기능

  • 실시간 반응형 창 크기 조정 리스너
  • Tailwind/Bootstrap 표준 중단점 감지(sm, md, lg, xl, 2xl)
  • 보고서에는 색상 심도, 터치 지원 및 방향이 표시됩니다.

사용 방법

  1. 뷰포트 크기 변경을 관찰하려면 브라우저 창 크기를 조정하세요.
  2. 프런트엔드 스타일 지정에 대한 현재 응답 중단점을 확인하세요.
  3. 반응형 버그 보고서에 첨부하려면 '디스플레이 사양 복사'를 클릭하세요.

자주 묻는 질문

장치 픽셀 비율(DPR)이란 무엇입니까?

DPR은 물리적 디스플레이 픽셀과 CSS 논리 픽셀 간의 비율입니다. Apple Retina 화면의 DPR은 일반적으로 2.0x인 반면, 4K 모니터의 범위는 1.5x~3.0x입니다.

내가 구입한 모니터보다 화면이 좁은 이유는 무엇인가요?

페이지에서 CSS 픽셀을 보고합니다. DPR 2의 2880 너비 패널은 1440 CSS 픽셀입니다.

Tailwind 라벨로 인해 내 페이지가 변경되나요?

아니요. 현재 너비만 지정합니다. Tailwind를 로드하지 않습니다.
