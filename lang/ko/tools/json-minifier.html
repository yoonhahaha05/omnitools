개요 및 알고리즘 메커니즘

축소하면 JSON이 데이터로 처리하지 않는 공백(문자열 외부의 공백, 탭, 줄 바꿈)이 삭제됩니다. 키, 값, 유형은 동일하게 유지됩니다. 문자열 내부의 공백은 유지됩니다. 페이지는 또한 전후의 바이트 크기를 보고합니다.

작업된 예입니다. 예쁜 객체 {"a": 1, "b": [2, 3]}는 {"a":1,"b":[2,3]}로 축소됩니다. 두 문자열 중 하나를 구문 분석하면 동일한 개체가 제공됩니다. 문자열 값 "hello world"에는 여전히 공백이 포함되어 있습니다. 입력이 유효한 JSON이 아닌 경우 축소할 항목이 없습니다. 먼저 Beautifier의 구문을 수정하세요.

사용 예

  • 작은 물체: {"a": 1, "b": [2, 3]}은 {"a":1,"b":[2,3]}이 됩니다.
  • 문자열 필드: "hello world"의 공백은 그대로 유지됩니다. 서식 지정 공백만 제거됩니다.

기능

  • 줄바꿈과 들여쓰기를 깔끔하게 제거합니다.
  • 정확한 바이트 크기와 압축 비율을 계산합니다.
  • 클라이언트 측 검증

사용 방법

  1. JSON 페이로드를 붙여넣으세요.
  2. JSON 축소를 클릭합니다.
  3. 압축된 문자열을 복사합니다.

자주 묻는 질문

JSON을 축소하면 데이터가 변경되나요?

아니요. 모든 키, 값, 유형 및 구조는 100% 동일하게 유지됩니다.

키 순서가 바뀌나요?

아니요. 열쇠는 나타난 순서대로 유지됩니다.

댓글이 삭제되나요?

JSON에는 댓글이 없습니다. // 주석이 있는 파일은 유효하지 않으며 주석이 사라질 때까지 축소되지 않습니다.
