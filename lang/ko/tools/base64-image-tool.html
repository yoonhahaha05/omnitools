개요 및 알고리즘 메커니즘

이미지 파일은 브라우저에서 읽고 데이터 URI(data:image/png;base64)와 그 뒤에 표준 Base64 바이트로 인쇄됩니다. 동일한 문자열을 img src 또는 CSS url()로 사용할 수 있습니다. 디코딩하면 해당 URI를 구문 분석하고 바이트를 파일로 다시 다운로드할 수 있습니다. 아무것도 업로드되지 않았습니다.

작업된 예입니다. 1픽셀 PNG는 Base64의 PNG 서명인 iVBORw0KGgo로 시작하는 짧은 Base64 본문입니다. URI는 파일보다 약 4/3 정도 크므로 30KB 아이콘은 약 40KB의 텍스트가 됩니다. 그 거래는 이메일의 작은 아이콘에 합리적입니다. 사진을 찍는 것은 좋지 않은 거래입니다.

사용 예

  • 작은 아이콘: 데이터 URI는 data:image/png;base64로 시작하며 img src일 수 있습니다.
  • 왕복: 해당 URI를 디코딩하여 동일한 PNG 바이트를 다운로드합니다.

기능

  • 드래그 앤 드롭 이미지 업로드
  • HTML <img> 및 CSS 배경 태그를 생성합니다.
  • 직접 이미지 파일 다운로드

사용 방법

  1. 인코딩하려면 이미지 파일을 업로드하고, 디코딩하려면 Base64 URI를 붙여넣으세요.
  2. 인코딩된 문자열을 복사하거나 이미지를 다운로드하세요.

자주 묻는 질문

Base64 이미지는 언제 사용해야 합니까?

Base64 이미지는 작은 아이콘, 로고 및 이메일 템플릿에 대한 HTTP 요청 왕복을 제거합니다.

텍스트가 파일보다 길어 보이는 이유는 무엇입니까?

Base64는 3바이트마다 4개의 문자와 data: 접두사를 사용합니다. 약 33% 증가할 것으로 예상됩니다.

어떤 이미지 유형이 허용되나요?

파일은 브라우저가 보고하는 유형(일반적으로 PNG, JPEG, WebP 또는 GIF)으로 인코딩됩니다.
