개요 및 알고리즘 메커니즘

필터는 캔버스에서 실행됩니다. 그레이스케일은 색상을 떨어뜨립니다. 세피아는 픽셀을 갈색으로 매핑합니다. 반전은 각 채널을 255에서 그 자체를 뺀 값으로 바꿉니다. 밝기와 대비는 샘플의 크기를 조정합니다. 흐림은 이웃을 평균화합니다. 다운로드는 브라우저가 할당할 수 있는 최대 소스 픽셀 크기의 PNG로 필터링된 캔버스입니다.

작업된 예입니다. 흰색 픽셀 rgb(255, 255, 255)는 회색조 및 반전에서 흰색으로 유지됩니다. 반전된 빨간색 픽셀 rgb(255, 0, 0)은 청록색인 rgb(0, 255, 255)가 됩니다. 해당 빨간색의 회색조는 중간 정도의 어두운 회색입니다. 일반적인 휘도 혼합에서 빨간색의 가중치가 녹색보다 낮기 때문입니다. 반전을 두 번 적용하면 원래 색상이 반환됩니다. 소스 파일은 덮어쓰지 않습니다.

사용 예

  • 문서 스캔: 그레이스케일을 누른 다음 대비를 높이고 PNG를 다운로드합니다.
  • 부정적인 점: 한번 뒤집어 보세요. 원래 색상을 다시 필요로 하는 경우 다시 반전하세요.

기능

  • 실시간 HTML5 Canvas 필터 파이프라인
  • 즉각적인 원클릭 사전 설정: B&W 느와르, 세피아 및 대비 강화
  • 처리된 이미지를 PNG로 직접 다운로드

사용 방법

  1. 이미지를 선택하거나 사전 설정된 캔버스로 테스트해 보세요.
  2. 회색조 또는 밝기 슬라이더를 조정합니다.
  3. 저장하려면 '필터링된 이미지 다운로드'를 클릭하세요.

자주 묻는 질문

필터를 적용하면 이미지 해상도가 감소합니까?

이 도구는 캔버스 한도까지 기본 해상도로 이미지를 처리하고 선명한 PNG 이미지를 출력합니다.

필터는 CSS filter()와 동일합니까?

모양이 그 효과와 일치합니다. 여기의 결과는 다운로드된 픽셀에 구워집니다. img 요소에 대한 CSS 규칙이 아닙니다.

필터가 픽셀 크기를 변경합니까?

아니요. 너비와 높이는 동일하게 유지됩니다. 흐림 효과는 가장자리를 자르지 않습니다.
