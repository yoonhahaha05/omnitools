개요 및 알고리즘 메커니즘

DevTools의 컬 명령에는 이미 메서드, URL, 헤더 및 본문이 포함되어 있습니다. 이 페이지는 해당 부분을 읽고 가져오기 또는 Python 요청과 동일한 요청을 인쇄합니다. 요청을 보내지 않습니다.

작업된 예입니다. 컬 -X POST https://example.com/api -H 'Content-Type: application/json' -d '{"a":1}' 는 POST 메서드, 해당 헤더 및 본문 '{"a":1}'을 사용하는 가져오기 호출과 동일한 헤더 및 json 또는 데이터 인수를 사용하는 요청.포스트 호출이 됩니다. A -H 'Authorization: Bearer…'를 통해 복사됩니다. 붙여넣은 컬에 포함된 경우 출력을 비밀로 처리하십시오.

사용 예

  • DevTools의 게시물: 메서드, URL, JSON 헤더 및 본문이 가져오기 및 요청에 포함됩니다.
  • 무기명 토큰: Authorization 헤더가 복사됩니다. 커밋하지 마십시오.

기능

  • URL, HTTP 동사, 헤더, 요청 본문을 자동으로 추출합니다.
  • 관용적인 JavaScript 및 Python을 출력합니다.
  • 원클릭 코드 복사

사용 방법

  1. Chrome DevTools 또는 문서에서 cURL 명령을 붙여넣습니다.
  2. 언어 탭을 선택하세요.
  3. 프로젝트에 코드를 복사합니다.

자주 묻는 질문

Chrome DevTools에서 cURL을 얻으려면 어떻게 해야 하나요?

네트워크 탭에서 네트워크 요청을 마우스 오른쪽 버튼으로 클릭하고 복사 -> cURL로 복사를 선택합니다.

Chrome에서 컬을 어디에 복사하나요?

DevTools, Network, 요청을 마우스 오른쪽 버튼으로 클릭하고 복사, cURL로 복사를 클릭합니다.

쿠키가 쿠키병으로 바뀌나요?

쿠키 헤더가 헤더로 복사됩니다. 페이지는 요청 세션이나 브라우저 쿠키 저장소를 생성하지 않습니다.
