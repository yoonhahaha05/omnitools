개요 및 알고리즘 메커니즘

소수 단위는 수천을 셉니다. 1KB = 1,000바이트, 1MB = 1,000,000바이트, 1GB = 1,000,000,000바이트, 1TB = 10^12바이트. 이진 단위는 1,024의 거듭제곱을 계산합니다. 1KiB = 1,024바이트, 1MiB = 1,048,576바이트, 1GiB = 1,073,741,824바이트. 드라이브 제조업체는 십진수를 사용합니다. Windows 파일 크기는 바이너리를 사용하고 GB로 레이블을 지정합니다.

작업된 예입니다. 1TB로 판매되는 드라이브는 1,000,000,000,000바이트를 저장합니다. 1,073,741,824로 나누면 931.32GiB이므로 Windows에서는 약 931GB를 보고합니다. 500,000,000바이트 파일은 10진수 500MB 및 476.84MiB입니다.

사용 예

  • 1TB 드라이브: Windows에서는 931.32GiB.
  • 500,000,000바이트 파일: 10진수 500MB 또는 476.84MiB.

기능

  • 바이트에서 테라바이트까지 포괄
  • 마케팅 스토리지(GB)와 실제 Windows 용량(GiB)을 비교합니다.
  • 고정밀 십진수 계산

사용 방법

  1. 파일 또는 드라이브 크기를 입력합니다.
  2. 소스 단위를 선택합니다.
  3. 모든 저장 형식에서 정확한 크기를 읽습니다.

자주 묻는 질문

Windows에서 1TB 하드 드라이브의 용량이 931GB에 불과한 이유는 무엇입니까?

제조업체는 십진수 기가바이트(10^9바이트)를 사용하여 드라이브를 판매하는 반면 Windows는 이진수 기가바이트(2^30바이트)를 사용하여 계산합니다.

1킬로바이트는 1,024바이트인가요?

바이너리 이름 지정에서는 1,024바이트인 1키비바이트입니다. 드라이브 레이블에 사용되는 십진법의 1킬로바이트는 1,000바이트입니다. 이 페이지에는 두 가지가 모두 표시됩니다.

드라이브 용량이 1,024가 아닌 이유는 무엇입니까?

제조업체는 10의 거듭제곱을 사용합니다. 931GB 수치는 1,024의 거듭제곱으로 작성된 바이트 수와 같습니다.
