개요 및 알고리즘 메커니즘

메모는 페이지가 소유한 키 아래 이 원본의 localStorage에 저장됩니다. 각 변경 사항은 현재 텍스트를 씁니다. 탭을 닫아도 localStorage는 지워지지 않습니다. 사이트 데이터를 지우거나 개인 창을 사용하거나 다른 브라우저 프로필을 열면 됩니다. 단어 수는 다른 곳에서 사용되는 것과 동일한 공백 분할입니다(잘린 텍스트, 공백 분할). 다운로드는 현재 내용의 .txt 파일을 작성합니다. 텍스트는 서버로 전송되지 않습니다.

작업된 예입니다. 1,200자 메모는 몇 킬로바이트입니다. 브라우저는 일반적으로 원본의 localStorage에 약 5MB를 허용하므로 패드는 문서 보관용이 아닌 메모용입니다. 저장소가 가득 차면 쓰기가 실행되고 최신 편집 내용은 화면에만 유지됩니다. 인터넷 사용 기록을 삭제하기 전에 사본을 내보내세요.

사용 예

  • 내일 다시 열리는 초안: 이 브라우저의 localStorage에는 아직 남아 있습니다.
  • 백업: .txt를 다운로드하세요. 사이트 데이터를 지우면 저장된 복사본이 삭제됩니다.

기능

  • 브라우저 LocalStorage에 지속적인 자동 저장
  • 100% 비공개: 메모가 외부 서버에 업로드되거나 동기화되지 않습니다.
  • 원클릭 일반 텍스트(.txt) 파일 다운로드

사용 방법

  1. 스크래치패드에 메모를 입력하거나 붙여넣습니다.
  2. 텍스트는 즉시 자동으로 백그라운드에 저장됩니다.
  3. 언제든지 메모를 내보내려면 '.txt 다운로드'를 클릭하세요.

자주 묻는 질문

브라우저 탭을 닫으면 내 노트가 사라지나요?

아니요. 메모는 브라우저의 영구 `localStorage`에 저장되며 OmniTools를 다시 방문할 때마다 다시 로드됩니다.

내 휴대폰과 동기화되나요?

아니요. localStorage는 이 브라우저 프로필에 유지됩니다. 다운로드와 함께 텍스트를 이동하거나 복사하세요.

다른 웹사이트에서 메모를 읽을 수 있나요?

아니요. 브라우저는 localStorage를 동일한 출처에만 노출합니다.
