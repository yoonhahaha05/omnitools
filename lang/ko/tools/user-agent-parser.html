개요 및 알고리즘 메커니즘

User-Agent 헤더는 브라우저가 각 요청과 함께 보내는 단일 행입니다. 이 페이지는 해당 행을 브라우저 이름, 버전, 엔진, OS 및 장치 클래스로 토큰화합니다. 동일한 파서가 현재 navigator.userAgent 또는 로그에서 붙여넣은 문자열에서 실행됩니다.

작업된 예입니다. 현재 Windows용 Chrome 제품군에는 Mozilla/5.0, Windows NT 10.0, AppleWebKit, Chrome/ 및 버전, Safari/537.36이 포함되어 있습니다. Safari 토큰은 Safari의 증거가 아닌 역사적 호환성입니다. Chrome 토큰이 있으므로 브라우저는 Chrome입니다. Googlebot 라인에는 Googlebot과 브라우저 호환성 섹션이 포함되어 있습니다. 결과를 힌트로 취급하십시오. 클라이언트는 원하는 문자열을 보낼 수 있습니다.

사용 예

  • 귀하의 브라우저: 페이지는 navigator.userAgent를 읽고 브라우저와 OS에 레이블을 지정합니다.
  • 로그 라인: 해당 브라우저를 실행하지 않고도 동일한 필드를 보려면 캡처된 헤더를 붙여넣으세요.

기능

  • 활성 브라우저 사용자 에이전트를 자동 감지합니다.
  • Chrome, Firefox, Safari, Edge, Android, iOS, Windows, macOS를 식별합니다.
  • 측정항목 배지 청소

사용 방법

  1. 현재 브라우저 메타데이터를 보거나 원격 사용자 에이전트 문자열을 붙여넣으세요.
  2. 구문 분석된 세부정보를 검사합니다.

자주 묻는 질문

사용자 에이전트란 무엇입니까?

사용자 에이전트는 웹 콘텐츠를 요청하는 애플리케이션, OS 및 소프트웨어 공급업체를 식별하는 HTTP 요청 헤더 문자열입니다.

Chrome과 Edge 모두 Safari를 언급하는 이유는 무엇입니까?

그들은 이전 서버 확인에서 거부되지 않도록 기록 토큰을 보관했습니다. 파서는 Chrome 또는 Edg 토큰을 사용하여 실제 브라우저를 선택합니다.

액세스 제어를 위해 이를 사용할 수 있습니까?

아니요. 헤더가 인증되지 않았습니다. 통계 및 디버깅에 사용합니다.
