개요 및 알고리즘 메커니즘

OmniTools UUID 생성기는 RFC 4122를 엄격히 준수하는 암호화 보안 버전 4 범용 고유 식별자를 생성합니다. 버전 4 UUID에는 128비트 데이터가 포함되어 있으며, 122비트는 암호화 보안 의사 난수 생성기(CSPRNG)에서 생성되었으며, 4비트는 버전 식별자(`0100` = 버전 4)용으로 예약되어 있고, 2비트는 RFC 4122 변형용으로 사용됩니다. ('10' = 변형 1). 두 개의 동일한 v4 UUID(충돌)가 생성될 확률은 매우 작습니다. $2^{122}$ 중 약 1(또는 $5.3 \times 10^{36}$ 중 약 1)입니다. 100년 동안 초당 10억 개의 UUID를 생성하더라도 중복 가능성은 10억 분의 1 미만으로 유지됩니다. 생성기는 브라우저에서 crypto.getRandomValues()를 사용합니다.

기술 사양

UUID 버전세대 기준무작위 비트RFC 표준충돌 위험
버전 1MAC 주소 및 타임스탬프0비트(결정적)RFC 4122 §4.2기계 추적 위험
버전 3MD5 해시 및 네임스페이스0비트(결정적)RFC 4122 §4.3MD5 충돌에 취약함
버전 4CSPRNG 무작위 엔트로피122비트RFC 4122 §4.4충돌 위험이 거의 없음
버전 5SHA-1 해시 및 네임스페이스0비트(결정적)RFC 4122 §4.3결정적/재현성

사용 예

  • 데이터베이스 기본 키: 분산 데이터베이스 클러스터(PostgreSQL, MongoDB, CockroachDB) 전반에 걸쳐 전역적으로 고유한 비순차적 엔터티 ID를 생성합니다.
  • 분산 추적 및 관찰 가능성: 마이크로서비스 HTTP 헤더 전체에 고유한 요청 ID(X-Correlation-ID)를 할당합니다.
  • 세션 및 토큰 관리: 추측할 수 없는 nonce 값을 생성하고 임시 거래 토큰을 보호합니다.

UUID 생성을 위한 터미널 및 코드 등가물

배쉬/터미널 CLI:
# Generate v4 UUID in Linux / macOS
uuidgen

# Generate lowercase v4 UUID via python
python3 -c "import uuid; print(uuid.uuid4())"
파이썬 3:
import uuid

# Generate RFC 4122 v4 UUID
new_id = uuid.uuid4()
print(f'Standard UUID: {new_id}')
print(f'Hex digits: {new_id.hex}')
자바스크립트/Node.js:
// Native Web Crypto UUID (Browser & Node.js 16+)
const uniqueId = crypto.randomUUID();
console.log(uniqueId);

기능

  • 기본 웹 암호화로 구동되는 암호화 방식으로 안전한 무작위성
  • 한 번의 클릭으로 1~100개의 UUID 생성
  • 대문자 및 하이픈 생략 옵션

사용 방법

  1. 필요한 UUID 수를 설정하십시오.
  2. 서식 환경설정을 선택하세요.
  3. '새로 생성'을 클릭하고 복사하세요.

자주 묻는 질문

UUID v4란 무엇입니까?

버전 4 UUID는 충돌 가능성이 무시할 수 있는 난수를 사용하여 생성된 128비트 식별자입니다.

두 명의 사용자가 동일한 UUID v4를 생성할 수 있습니까?

정상적인 작동 조건에서는 통계적으로 불가능합니다. 122비트의 실제 엔트로피를 사용하면 $5.3 \times 10^{36}$의 가능한 조합이 가능합니다. 이는 관측 가능한 우주에 있는 별의 수를 훨씬 초과하는 수치입니다.

UUID가 대시(8-4-4-4-12)로 형식화된 이유는 무엇입니까?

표준 8-4-4-4-12 16진수 그룹화는 RFC 4122에 정의된 대로 버전 1 UUID(time_low, time_mid, time_hi_and_version, clock_seq, node)의 과거 하위 필드를 나타냅니다.

생성된 UUID가 저장되거나 추적됩니까?

절대. 생성은 브라우저의 웹 암호화 하위 시스템을 통해 컴퓨터에서 100% 로컬로 실행됩니다.
