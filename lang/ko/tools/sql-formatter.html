개요 및 알고리즘 메커니즘

포맷터는 인식된 키워드를 대문자로 표시하고 주요 절을 해당 줄에 배치합니다. SELECT, FROM, WHERE, JOIN, GROUP BY, ORDER BY 및 LIMIT는 일반적인 구분 기호입니다. 데이터베이스에 연결하지 않으며 테이블이 존재하는지 확인하지 않습니다. 인용한 식별자는 작성한 그대로 유지됩니다.

작업된 예입니다. 활성 = 1인 사용자의 ID, 이름을 선택하면 이름별 주문이 SELECT 목록, FROM 행, WHERE 행 및 ORDER BY 행이 되며 키워드는 대문자로 표시됩니다. 문자열 리터럴 'select'는 데이터이므로 대문자로 표시되지 않습니다. 누락된 쉼표는 서식을 지정한 후에도 여전히 누락된 쉼표입니다.

사용 예

  • 한 줄 쿼리: SELECT, FROM, WHERE 및 ORDER BY 각 토지는 자체 라인에 있습니다.
  • 문자열 내부의 키워드: 'select'는 소문자로 유지됩니다.

기능

  • 표준 SQL 키워드(SELECT, FROM, WHERE, JOIN)를 대문자로 표시합니다.
  • 논리절 줄바꿈을 추가합니다.
  • PostgreSQL, MySQL 및 SQLite 방언 구문 지원

사용 방법

  1. 형식화되지 않은 SQL 문을 붙여넣습니다.
  2. SQL 형식을 클릭합니다.
  3. 결과를 복사합니다.

자주 묻는 질문

내 데이터베이스에 대해 쿼리를 실행합니까?

아니요, 엄격히 말하면 데이터베이스 연결이 없는 클라이언트측 문자열 포맷터입니다.

누락된 쉼표가 추가되거나 잘못된 조인이 수정됩니까?

아니요. 공백과 키워드 대소문자만 변경됩니다.

키워드는 어떤 방언에서 왔나요?

PostgreSQL, MySQL, SQLite에서 사용되는 공유 코어입니다. 공급업체별 기능은 식별자로 남습니다.
