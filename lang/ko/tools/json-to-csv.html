JSON을 CSV로

JSON을 붙여넣습니다. Excel이나 스프레드시트에서 열 수 있는 CSV가 제공됩니다.

개요 및 알고리즘 메커니즘

입력은 객체의 배열이어야 합니다. 헤더 행은 키의 합집합이므로 키를 생략한 객체는 여전히 열을 갖습니다. 누락된 값은 빈 셀입니다. 쉼표, 따옴표 또는 개행 문자가 포함된 필드는 큰따옴표로 묶이고 내부의 따옴표는 두 배가 됩니다.

작업된 예입니다. [{"name":"Ada","city":"Paris"},{"name":"Bo","note":"hello, world"}]는 헤더 이름,city,note 및 노트 셀이 인용된 두 번째 데이터 행("hello, world")이 됩니다. Bo에는 도시가 없으므로 해당 셀은 비어 있습니다. Ada에는 메모가 없으므로 메모 셀이 비어 있습니다.

사용 예

  • 두 개체: 하나의 개체에 도시가 없는 경우에도 키가 하나의 헤더로 병합됩니다.
  • 값의 쉼표: hello, world가 인용되므로 스프레드시트에서는 이를 하나의 셀에 보관합니다.

기능

  • JSON 키에서 자동 헤더 추출
  • RFC 호환 견적 이스케이프
  • 원클릭 CSV 다운로드

사용 방법

  1. JSON 개체 배열을 붙여넣습니다.
  2. 생성된 CSV 출력을 검토합니다.
  3. 다운로드하거나 복사하세요.

자주 묻는 질문

객체에 다른 키가 있으면 어떻게 되나요?

변환기는 데이터가 손실되지 않도록 모든 개체의 모든 고유 키를 병합합니다.

배열에 없는 객체 하나를 변환할 수 있나요?

[ ] 안에 넣으세요. 변환기에는 행 목록이 필요합니다.

중첩된 객체는 어떻게 되나요?

중첩된 개체는 열로 병합되지 않습니다. 먼저 문자열화하지 않으면 단일 셀로 표시됩니다.
