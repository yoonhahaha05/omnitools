개요 및 알고리즘 메커니즘

클릭은 기본 스레드가 사용 중일 때 계속 실행되는 웹 오디오 시계에 예약됩니다. 클릭 사이의 간격은 60/BPM초입니다. 마디의 비트 1은 더 높은 피치이므로 다운비트를 들을 수 있습니다. 박자 기호는 마디에 클릭 수를 설정합니다(4/4에 4회, 3/4에 3회, 2/4에 2회, 6/8에 6회).

작업된 예입니다. 120BPM은 클릭 간 60/120 = 0.5초, 즉 500밀리초입니다. 60BPM은 1,000밀리초입니다. 90BPM은 666.7밀리초입니다. 120BPM의 4/4박자에서는 마디가 2초 동안 지속됩니다. 탭 템포는 탭 사이의 간격에서 BPM을 채우는데, 이는 별도의 탭 템포 도구와 동일한 아이디어입니다.

사용 예

  • 4/4박자에 120BPM: 500ms마다 클릭하고 2초마다 막대를 클릭합니다.
  • 왈츠: 90BPM의 3/4은 667ms마다 클릭되고 세 번째 클릭마다 악센트가 표시됩니다.

기능

  • 샘플 수준의 정확한 Web Audio API 발진기 합성
  • 템포 계산기를 탭하여 노래를 귀별로 쉽게 일치시키세요.
  • 동적 박자표(4/4, 3/4, 2/4, 6/8)를 사용하여 비트 1에 악센트 피치를 추가합니다.

사용 방법

  1. 슬라이더를 드래그하거나 'Tap Tempo' 버튼을 탭하여 목표 BPM을 설정하세요.
  2. 박자표를 선택하세요.
  3. 연습하려면 '메트로놈 시작'을 클릭하세요.

자주 묻는 질문

일부 온라인 메트로놈이 시간을 잃는 이유는 무엇입니까?

표준 JavaScript `setInterval`은 CPU가 사용량이 많을 때마다 표류합니다. OmniTools는 하드웨어 수준 `AudioContext.currentTime` 예측 예약을 사용하여 정확한 리듬을 유지합니다.

setInterval을 사용하지 않는 이유는 무엇입니까?

탭이 사용 중이면 setInterval이 표류합니다. AudioContext 예약은 그렇지 않습니다.

6/8은 무엇을 바꾸나요?

악센트 패턴입니다. 여섯 번 클릭하면 막대가 완성됩니다. BPM 컨트롤은 여전히 ​​클릭 간격을 설정합니다.
