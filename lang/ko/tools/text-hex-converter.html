개요 및 알고리즘 메커니즘

16진수는 각 바이트를 0-9 및 a-f의 두 자리 숫자로 표시합니다. "Hi"는 UTF-8 바이트 48 69입니다. 동일한 바이트는 공백을 사용하여 원시 문자열 4869 또는 C 스타일 0x48 0x69로 인쇄될 수 있습니다. 디코딩하면 그 반대가 됩니다. 홀수 길이 16진수는 바이트가 항상 두 자리이기 때문에 불완전합니다.

작업된 예입니다. "A"는 41입니다. 단어 "cat"은 63 61 74입니다. "A"의 C 스타일 덤프는 0x41입니다. URL 스타일 퍼센트 인코딩은 다른 표기법입니다. %41도 "A"이지만 이 페이지는 퍼센트 이스케이프가 아닌 16진수 바이트를 인쇄합니다. 백분율 인코딩에는 URL 인코더를 사용하십시오.

사용 예

  • A: 16진수 41 또는 C 스타일의 0x41입니다.
  • cat: 63 61 74.

기능

  • 형식 옵션: 공백 구분, C 스타일 0x 표기법, 원시 문자열
  • 전체 UTF-8/ASCII 바이트를 처리합니다.
  • 양방향 즉시 변환

사용 방법

  1. 텍스트를 입력하거나 16진수를 붙여넣으세요.
  2. 출력 형식을 선택합니다.
  3. 출력을 복사합니다.

자주 묻는 질문

16진수란 무엇입니까?

16진수는 각 바이트를 0-9와 a-f의 두 문자로 나타내는 16진수 시스템입니다.

디코딩할 때 문자는 대소문자를 구분합니까?

4A번과 4a번은 같은 바이트입니다.

16진수 문자열의 자릿수가 홀수이면 어떻게 되나요?

마지막 숫자는 전체 바이트가 아닙니다. 디코드를 신뢰하기 전에 이를 삭제하거나 앞에 0을 추가하십시오.
