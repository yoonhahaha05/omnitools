이미지 자르기

이미지를 삭제하세요. 프레임을 선택하고 다운로드하세요. 파일은 이 장치에 유지됩니다.

개요 및 알고리즘 메커니즘

자르기는 고정된 종횡비의 중앙 창입니다. 1:1은 정사각형으로 아바타에 사용됩니다. 4:3은 예전 사진과 슬라이드 비율입니다. 16:9는 와이드스크린입니다. 확대/축소 슬라이더는 해당 창 뒤의 이미지 크기를 조정합니다. 내보내기는 창을 PNG로 그립니다. 창 밖의 얼굴은 파일에 없습니다.

작업된 예입니다. 4000×3000 사진은 이미 4:3이므로 확대/축소 1에서 4:3 자르기를 하면 전체 프레임이 유지됩니다. 동일한 사진의 1:1 자르기는 중간 3000×3000을 사용하고 양쪽에서 500픽셀을 떨어뜨립니다. 16:9 자르기에서는 전체 너비와 더 짧은 높이(4000 × (9/16) = 높이 2250픽셀, 수직 중앙)를 사용합니다.

사용 예

  • 아바타: 1:1, 얼굴이 정사각형을 채울 때까지 확대됩니다.
  • 4:3 사진의 16:9 스틸: 전체 너비가 유지됩니다. 상단과 하단이 잘립니다.

기능

  • 1:1, 4:3 및 16:9 표준 화면비 사전 설정
  • 피사체의 구도를 잡는 중앙 줌 슬라이더
  • 직접 무손실 PNG 내보내기

사용 방법

  1. 장치에서 이미지 파일을 업로드하세요.
  2. 가로세로 비율 버튼을 선택합니다(예: 소셜 아바타의 경우 1:1).
  3. 자른 PNG를 다운로드하세요.

자주 묻는 질문

프로필 사진에 가장 적합한 화면 비율은 무엇입니까?

GitHub, Twitter, Discord 및 Slack의 프로필 아바타에는 1:1 정사각형 종횡비가 표준입니다.

자르기 직사각형을 모서리로 끌 수 있나요?

창은 중앙에 유지됩니다. 확대/축소를 사용하여 가운데 부분을 얼마나 유지할지 선택하세요.

다운로드 형식은 무엇입니까?

PNG. JPEG가 필요한 경우 나중에 변환하세요.
