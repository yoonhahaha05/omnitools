개요 및 알고리즘 메커니즘

단어 카운터는 공백으로 텍스트를 분할합니다. 클라이언트 측과 같이 하이픈으로 연결된 단어는 구두점이 아닌 공백, 탭 및 줄 바꿈에서 분할이 발생하기 때문에 한 단어로 유지됩니다. 문자는 공백을 포함한 문자열의 길이입니다. 공백이 없는 수는 공백을 먼저 제거합니다.

문장은 마침표, 물음표 또는 느낌표로 끝나는 텍스트의 연속입니다. 단락은 빈 줄로 구분된 블록입니다.

읽는 시간은 성인이 조용히 읽는 일반적인 추정치인 분당 200단어를 사용합니다. 페이지에는 1분에 도달할 때까지의 지속 시간이 초 단위로 표시됩니다.

작업된 예입니다. 다음 줄을 붙여넣으세요.

지금 JSON 포맷터를 배송해 보세요. 병합하기 전에 차이점을 확인하세요.

11단어, 63자, 공백 없이 53자입니다. 2문장 1문단 입니다. 읽기 시간은 3초입니다. 분당 200단어의 11단어는 3.3초이고 카운터는 이를 3으로 반올림하기 때문입니다.

사용 예

  • 콘텐츠 및 카피라이팅: Google 검색 메타 제목(50~60자), 메타 설명(150~160자) 및 소셜 미디어 게시물에 대해 엄격한 문자 제한을 준수합니다.
  • 학술 및 에세이 작성: 대학 논문, 장학금 에세이, 학술지의 단어 수 경계를 모니터링합니다.
  • 기조연설 및 팟캐스트 준비: 컨퍼런스 프리젠테이션 및 음성 해설 스크립트의 정확한 음성 전달 시간을 추정합니다.

# Count words, lines, and bytes in Linux

파이썬 3:

// Precise JS word counting regex

const readingTimeMin = Math.ceil(words / 200);

기능

  • 대기 시간이 없는 실시간 대응 계산
  • 공백을 구분하고 공백이 없는 문자 측정항목을 포함합니다.
  • 표준 200wpm 읽기 속도를 기준으로 한 예상 읽기 시간
  • 100% 비공개: 텍스트가 로컬 브라우저나 장치를 떠나지 않습니다.

사용 방법

  1. 기본 입력 상자에 텍스트를 직접 붙여넣거나 입력하세요.
  2. 아래 요약 대시보드에서 즉시 업데이트되는 지표를 확인하세요.
  3. 도구를 테스트하려면 '샘플 텍스트'를 클릭하고 보드를 재설정하려면 '지우기'를 클릭하세요.

자주 묻는 질문

독서 시간은 어떻게 계산되나요?

읽기 시간은 성인의 조용히 읽기에 대한 업계 표준 벤치마크인 분당 200단어를 사용하여 계산됩니다.

내 텍스트가 원격 서버에 업로드되거나 저장됩니까?

결코. 모든 계산은 전적으로 JavaScript를 통해 브라우저 내에서 이루어집니다. OmniTools는 개인 또는 문서 데이터를 전혀 수집하지 않습니다.

독서 시간은 어떻게 계산되나요?

표준 성인 묵독 속도 벤치마크의 범위는 분당 200~250단어입니다. OmniTools는 명확한 이해를 위해 업계 표준인 200wpm 기준을 기본값으로 설정합니다.

OmniTools는 하이픈으로 연결된 단어를 어떻게 처리합니까?

'클라이언트 측' 또는 '실시간'과 같이 하이픈으로 연결된 단어는 표준 스타일 가이드 및 Google 검색 색인 규칙과 일치하는 단일 의미 단어 단위로 처리됩니다.

내 초안 텍스트가 어디에 저장되거나 색인화되나요?

절대. 텍스트는 브라우저 창을 떠나지 않습니다. 초안은 기록되거나 서버로 전송되거나 AI 교육에 사용되지 않습니다.
