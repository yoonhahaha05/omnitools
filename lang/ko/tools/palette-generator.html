개요 및 알고리즘 메커니즘

클릭할 때마다 조화 규칙에 따라 5가지 색상이 만들어집니다. 유사한 색상은 색상환에서 약 30도 간격으로 나란히 위치합니다. 보색은 180도 떨어져 반대편에 위치합니다. 잠금은 견본을 고정하므로 다음 클릭 시 잠금 해제된 견본만 변경됩니다. CSS 복사는 현재 16진수 값을 사용하여 --color-1부터 --color-5까지 사용자 정의 속성을 작성합니다.

작업된 예입니다. 유사한 세트의 기본 색상 210(파란색)은 청록색 범위에 유지됩니다. 보색 세트의 동일한 베이스는 30에 가까운 색조(주황색)를 추가합니다. 견본 3을 잠그고 다시 생성하면 해당 16진수는 유지되고 나머지 4개는 대체됩니다. 변수는 :root { --color-1: #1d4ed8; … }.

사용 예

  • 파란색 인터페이스: 유사한 조화는 임의의 반대 방향으로 점프하는 대신 색조 210 주위에 유지됩니다.
  • 유지하고 싶은 색상 중 하나: 해당 견본을 잠급니다. 생성은 나머지 4개를 대체합니다.

기능

  • 6가지 색상 조화 생성 알고리즘
  • 조합을 선별하기 위한 대화형 견본 잠금
  • 최신 CSS 사용자 정의 속성으로 내보내기(--color-1)

사용 방법

  1. 하모니 모드를 선택하거나 Harmonic Analogous를 선택하세요.
  2. '새로 생성'을 클릭하거나 버튼을 눌러 조합을 살펴보세요.
  3. 자물쇠 아이콘으로 원하는 색상을 잠그세요.
  4. 개별 16진수 코드를 복사하거나 'CSS 변수 복사'를 클릭하세요.

자주 묻는 질문

UI 디자인에 가장 적합한 색상 조화 알고리즘은 무엇입니까?

Harmonic Analogous 또는 Cool Tech 팔레트는 시각적 충돌 없이 균형 잡힌 대비를 제공하므로 소프트웨어 인터페이스에 가장 적합합니다.

팔레트가 저장되었나요?

아니요. 다시 생성하기 전에 16진수 값이나 CSS 변수를 복사하세요.

조화가 명암비를 보장하나요?

아니요. 대비 검사기에서 배경과 텍스트 색상을 확인하세요. 조화는 색조 간격에 관한 것입니다.
