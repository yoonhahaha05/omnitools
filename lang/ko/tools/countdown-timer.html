광고

개요 및 알고리즘 메커니즘

분과 초를 설정하거나 1, 5, 10, 15 또는 30분의 사전 설정을 사용합니다. 마감일은 시작을 누르면 계산됩니다. 각 프레임에는 해당 마감일까지 남은 시간이 표시되므로 탭이 멈춰도 카운트다운이 연장되지 않습니다. 0에서 페이지는 웹 오디오 발진기를 통해 짧은 차임을 재생합니다. 소리가 재생되려면 탭이 열려 있어야 합니다. 화면을 잠그거나 탭을 닫으면 소리가 나지 않습니다.

작업된 예입니다. 5분 사전 설정은 300초입니다. 12:00:00에 시작하여 12:05:00에 0에 도달합니다. 3시가 남은 상태에서 12시 2분에 일시 중지했다가 다시 시작하면 3분 후에 새로운 마감 시간이 예약됩니다. 원래의 12:05:00에 도달하려고 시도하지 않습니다.

사용 예

  • 5분 사전 설정: 시작을 누른 순간부터 300초.
  • 주방 타이머: 12분으로 설정하세요. 차임벨이 재생될 수 있도록 탭을 전경에 둡니다.

기능

  • Melodic 다중 톤 Web Audio API 완료 차임벨
  • 1, 5, 10, 15, 30분 간격의 빠른 사전 설정 버튼
  • 방 전체에서 읽을 수 있는 고대비 디지털 판독

사용 방법

  1. 빠른 사전 설정 버튼을 클릭하거나 분과 초를 입력하세요.
  2. '시작'을 클릭하세요.
  3. 카운트다운이 끝나면 오디오 차임 소리를 들어보세요.

자주 묻는 질문

화면이 꺼져 있거나 모바일에서도 차임벨이 작동하나요?

탭이 열려 있는 경우 오디오 차임벨은 브라우저 웹 오디오를 통해 직접 재생됩니다.

탭이 배경에 있으면 차임벨이 울리나요?

브라우저는 백그라운드 타이머를 제한하고 종종 오디오를 차단합니다. 소리가 필요한 경우 탭을 열어두고 집중하세요.

영업시간을 설정할 수 있나요?

합계를 분 단위로 입력하세요. 90분은 1시간 30분입니다.
