Descripción general y mecánica algorítmica

El codificador y decodificador OmniTools Base64 convierte datos binarios y de cadena a representaciones ASCII radix-64 de conformidad con RFC 4648. La codificación Base64 toma 3 bytes de datos binarios (24 bits) y los asigna a 4 caracteres ASCII imprimibles (6 bits cada uno) elegidos de una tabla de índice de 64 caracteres (A–Z, a–z, 0–9, +, /). Cuando el recuento de bytes de entrada no es divisible por 3, se añaden caracteres de relleno '=" para mantener la alineación. Los estándares JavaScript btoa y atob incluyen caracteres fuera de Latin-1. Este codificador convierte primero el texto en bytes UTF-8, por lo que las letras acentuadas y los emoji son de ida y vuelta. El modo seguro para URL reemplaza + por - y / por _.

Ejemplo resuelto. Codifica la palabra OmniTools. El resultado es T21uaVRvb2xz. Decodificar esa cadena devuelve OmniTools. La palabra tiene 9 bytes, que se divide uniformemente entre 3, por lo que no hay relleno =.

Ejemplos de uso

  • Desarrollo web y API: Codificación de encabezados de autorización de autenticación básica (`Autorización: Básica `).
  • URI de datos y activos en línea: Incrustar pequeños iconos, fuentes e imágenes SVG directamente en archivos CSS y HTML.
  • Serialización de datos: Transmitir de forma segura cargas útiles binarias a través de canales de transmisión de solo texto (JSON, XML, correo electrónico).

Equivalentes de código y terminal para codificación y decodificación Base64

CLI de bash/terminal:
# Encode string to Base64 in Bash
echo -n "OmniTools" | base64

# Decode Base64 string
echo "T21uaVRvb2xz" | base64 --decode
Pitón 3:
import base64

# Unicode-safe Base64 in Python
encoded = base64.b64encode('OmniTools 🚀'.encode('utf-8')).decode('ascii')
decoded = base64.b64decode(encoded).decode('utf-8')
print(f'Encoded: {encoded} -> Decoded: {decoded}')
JavaScript/Node.js:
// Node.js Buffer Base64
const str = 'OmniTools 🚀';
const b64 = Buffer.from(str, 'utf-8').toString('base64');
const original = Buffer.from(b64, 'base64').toString('utf-8');
console.log({ b64, original });

Preguntas frecuentes

¿Qué es Base64 seguro para URL?

Base64 seguro para URL sustituye '+' por '-' y '/' por '_', y elimina los signos '=' del relleno final.

¿Base64 cifra mis datos?

No. Base64 es un esquema de codificación, NO cifrado. Cualquiera puede decodificar una cadena Base64 al instante. Nunca utilice Base64 solo para proteger contraseñas, claves o credenciales confidenciales.

¿Por qué Base64 aumenta el tamaño de los datos en ~33%?

Base64 representa 3 bytes (24 bits) de datos utilizando 4 caracteres ASCII (32 bits). Esta proporción de 4:3 crea naturalmente una expansión de gastos generales de aproximadamente el 33,3%.

¿Puedo codificar archivos binarios de forma segura?

Sí. Nuestra API FileReader del lado del cliente lee archivos binarios directamente en los buffers Uint8Array, lo que garantiza la fidelidad byte por byte sin pérdida de datos.
