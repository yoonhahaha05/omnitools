Descripción general y mecánica algorítmica

Un favicon es el pequeño ícono en una pestaña. 32×32 cubre las pestañas actuales del escritorio. 16×16 es el tamaño heredado. 180×180 es el ícono táctil de Apple que se usa cuando alguien guarda el sitio en una pantalla de inicio. Esta página dibuja una letra o un emoji en un mosaico de color con una de tres máscaras: cuadrado, cuadrado redondeado o círculo, y luego exporta un PNG. También imprime una etiqueta de enlace que puede colocar en el encabezado del documento.

Ejemplo resuelto. Una letra O blanca en #0f172a, cuadrado redondeado, exportada a 32×32, se denomina <link rel="icon" type="image/png" href="/favicon.png">. El archivo de 180×180 es <link rel="apple-touch-icon" href="/apple-touch-icon.png">. La representación de emoji depende de la fuente del sistema operativo, por lo que el mismo carácter puede verse diferente en Apple y Windows. Para una marca, prefiera una letra o una forma simple.

Ejemplos de uso

  • Una pestaña del navegador: Un PNG de 32×32 de una letra.
  • Una pantalla de inicio de iOS: El mismo diseño a 180×180, con rel apple-touch-icon.

Funciones

  • Vista previa en vivo de varios tamaños para pestañas del navegador y marcadores móviles
  • Forma de círculo, cuadrado redondeado y borde cuadrado
  • Fragmento HTML incluido para integración instantánea del sitio web

Pasos de uso

  1. Escribe el emoji, el carácter o la letra de tu marca.
  2. Elija un color de fondo y una forma de esquina.
  3. Haga clic en 'Descargar Favicon PNG 32x32'.

Preguntas frecuentes

¿Cuál es el tamaño estándar de favicon para sitios web?

32x32 píxeles es estándar para pestañas de navegador de escritorio con alto DPI, mientras que 16x16 se usa en pantallas heredadas y 180x180 para marcadores Apple Touch.

¿Necesito un archivo .ico?

Los navegadores modernos aceptan el PNG. Un .ico es sólo para clientes muy antiguos.

¿Por qué el emoji está recortado?

Algunos emoji son más anchos que un solo cuadrado. Utilice un carácter o cambie a una letra.
