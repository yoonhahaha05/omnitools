Descripción general y mecánica algorítmica

El decodificador OmniTools JWT inspecciona y descomprime tokens web JSON de acuerdo con RFC 7519. Un JWT consta de tres segmentos codificados en Base64URL separados por puntos: el encabezado (algoritmo y tipo de token), la carga útil (reclamaciones, asunto, emisor, vencimiento y datos personalizados) y la firma criptográfica. Esta página decodifica el encabezado y la carga útil. No comprueba la firma. Una verificación de firma necesita la clave pública o secreta, y esa clave no debe pegarse en una herramienta de navegador.

Ejemplo resuelto. El segmento de carga útil eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZSI6IkpvaG4gRG9lIiwiaWF0IjoxNTE2MjM5MDIyfQ se decodifica en {"sub":"1234567890","name":"John Doe","iat":1516239022}. El valor iat 1516239022 es 2018-01-18 01:30:22 UTC. Cualquiera que tenga el token puede leer esos reclamos. La firma sólo le dice al verificador que el emisor los firmó.

Ejemplos de uso

  • Conexión OAuth 2.0 y OpenID: Inspeccionar tokens de identificación y tokens de acceso emitidos por proveedores de identidad (Auth0, Okta, Firebase, AWS Cognito).
  • Auditorías de vencimiento de tokens: Verificar las afirmaciones de `exp` (vencimiento) y `nbf` (no antes) soluciona problemas de caídas de sesión de autenticación.
  • Verificación de acceso basada en roles: Auditar roles, alcances y reclamos de usuario integrados en encabezados de autorización de API.

Equivalentes de terminales y códigos para la inspección JWT

CLI de bash/terminal:
# Decode JWT payload in terminal using jq
TOKEN="ey..."
echo $TOKEN | cut -d. -f2 | base64 -d 2>/dev/null | jq .
Pitón 3:
import json, base64

token = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...'
payload_b64 = token.split('.')[1] + '=='
payload = json.loads(base64.urlsafe_b64decode(payload_b64))
print('JWT Claims:', json.dumps(payload, indent=2))
JavaScript/Node.js:
// Browser client-side JWT payload decoder
function parseJwt(token) {
  const base64Url = token.split('.')[1];
  const base64 = base64Url.replace(/-/g, '+').replace(/_/g, '/');
  return JSON.parse(decodeURIComponent(escape(atob(base64))));
}

Funciones

  • 100% privado: los tokens nunca se envían a un servidor de terceros
  • Decodifica estructuras JSON de encabezado y carga útil al instante
  • Calcula el tiempo de vencimiento legible por humanos a partir del reclamo de marca de tiempo "exp"

Pasos de uso

  1. Pegue su cadena JWT en el cuadro de entrada del token.
  2. Inspeccione el encabezado del algoritmo decodificado y reclame la carga útil JSON.
  3. Consulte el banner de vencimiento para conocer la validez del token.

Preguntas frecuentes

¿Puede esta herramienta verificar la firma JWT?

Signature verification requires the secret or public certificate. Client-side tools inspect and decode the claims without requiring your private keys.

¿Puede OmniTools verificar la firma criptográfica de mi JWT?

Los decodificadores pueden inspeccionar el encabezado y los reclamos sin una clave secreta. La verificación de firma requiere la clave privada o el secreto compartido, que nunca debe compartir con ninguna herramienta de navegador web.

¿Es seguro pegar aquí tokens de clientes reales?

Sí. OmniTools se ejecuta 100% en su navegador. Nunca se transmite, registra ni almacena en caché ningún dato de token en ningún servidor remoto.

¿Por qué mi token muestra "Caducado"?

El reclamo "exp" contiene una marca de tiempo Unix. OmniTools compara esto con el reloj actual de su dispositivo. Si el reloj del sistema de su computadora está desviado, verifique que la sincronización de hora esté habilitada.
