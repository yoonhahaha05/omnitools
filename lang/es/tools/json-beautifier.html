Descripción general y mecánica algorítmica

El embellecedor, validador y formateador JSON de OmniTools analiza documentos JSON sin procesar de acuerdo con las especificaciones RFC 8259. Construye una representación de sintaxis abstracta en la memoria del cliente, normaliza los escapes de cadenas, detecta errores de sintaxis estructurales (como claves sin comillas, comas finales o corchetes faltantes) y vuelve a serializar los datos con sangría configurable de 2 espacios, 4 espacios o tabuladores. El formateador utiliza JSON.parse y JSON.stringify del navegador. No acepta comentarios, claves entre comillas simples ni comas finales, porque no son JSON válidos.

Ejemplo resuelto. Pegue {"name":"Ada","ok":true} y elija sangría de 2 espacios. El resultado es:

{ "nombre": "Ada", "ok": verdadero }

Se rechaza una coma al final, como en {"name":"Ada",}. Elimine la coma y formatee nuevamente.

Ejemplos de uso

  • Depuración de API e inspección de carga útil: Formateo de cargas útiles REST y GraphQL JSON minificadas ilegibles devueltas desde servidores de producción.
  • Validación del archivo de configuración: Limpieza y eliminación de archivos de configuración complejos (package.json, tsconfig.json, Kubernetes ConfigMaps).
  • Saneamiento y minificación de datos: Eliminación de espacios en blanco y retornos de carro superfluos para optimizar los tamaños de transferencia de carga útil.

Equivalentes de terminal y código para formato JSON

CLI de bash/terminal:
# Pretty print JSON using jq
cat data.json | jq .

# Format JSON using Python CLI
python3 -m json.tool data.json
Pitón 3:
import json

raw = '{"name":"omnitools","status":200}'
parsed = json.loads(raw)
print(json.dumps(parsed, indent=2, sort_keys=True))
JavaScript/Node.js:
// JavaScript native JSON formatting
const raw = '{"tool":"json-beautifier","local":true}';
const formatted = JSON.stringify(JSON.parse(raw), null, 2);
console.log(formatted);

Preguntas frecuentes

¿Las comas finales son válidas en JSON?

No, la especificación JSON estándar prohíbe las comas finales.

¿Por qué JSON prohíbe las comas finales?

RFC 8259 prohíbe estrictamente las comas finales para garantizar un análisis sin ambigüedades en todos los lenguajes de programación y analizadores heredados más antiguos.

¿Puede OmniTools formatear archivos JSON enormes sin fallar?

Sí. Debido a que las operaciones se ejecutan directamente en la memoria del navegador local sin tiempos de espera de la red, puede formatear cómodamente archivos de hasta decenas de megabytes, dependiendo de la RAM disponible.

¿OmniTools admite JSON5 o JSON con comentarios?

El JSON estándar no permite estrictamente comentarios (// o /* */). Nuestro formateador cumple con el estándar oficial RFC 8259 para garantizar que la salida sea válida en todos los analizadores de producción.
