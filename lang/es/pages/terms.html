2. Naturaleza del software: 100% ejecución del lado del cliente

OmniTools proporciona microutilidades ejecutadas por el navegador diseñadas para procesar datos localmente dentro de la zona de pruebas de su navegador a través de JavaScript, HTML5 Canvas, Web Workers, Web Audio API y Web Cryptography API (SubtleCrypto).

Debido a que los cálculos se ejecutan en el lado del cliente en su hardware local, OmniTools no almacena, transmite, procesa ni realiza copias de seguridad de los archivos, contraseñas, claves criptográficas, fragmentos de código o textos que usted manipula. Usted mantiene la propiedad exclusiva y la responsabilidad de preservar sus datos originales y convertidos.

Aviso importante sobre los cálculos:

Si bien hacemos todo lo posible para cumplir con las especificaciones establecidas (RFC 8259, RFC 2104, estándares de punto flotante IEEE 754), los cálculos (incluidos el interés compuesto, los estimadores de impuestos, los límites de subred y los hashes criptográficos) no deben usarse como única base para decisiones financieras, legales, médicas o de seguridad vitales críticas.
