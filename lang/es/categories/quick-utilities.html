Estándares de privacidad y arquitectura de dominio

Las herramientas de productividad de OmniTools utilizan interfaces de hardware de navegador nativas, incluida la API de audio web para síntesis de audio de metrónomo sin latencia, la API de criptografía web para la generación de frases de contraseña CSPRNG y la API de sincronización de navegación para diagnósticos de latencia en tiempo real.

Preguntas frecuentes

¿Qué tan seguro es el generador de contraseñas?

Utiliza el estándar criptográfico window.crypto.getRandomValues() del navegador, lo que garantiza una verdadera entropía pseudoaleatoria criptográficamente segura.

¿Dónde almacena mis notas el Scratchpad?

Las notas se almacenan en la ventana local de su navegador. La zona de pruebas de almacenamiento local. Permanecen en su dispositivo incluso si cierra la pestaña.
