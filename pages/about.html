About OmniTools

A free, on-device web utility site for software engineers, writers, and analysts.

Why OmniTools Exists

The modern web is filled with utility websites that should be simple, but aren't. Most online JSON formatters, Base64 decoders, regex testers, and subnet calculators force users through bloated server-side round trips, intrusive cookie walls, captchas, and popup ads. Worse still, pasting confidential API tokens, environment variables, customer records, or internal passwords into an unfamiliar third-party server creates serious compliance and security risks.

OmniTools was created to prove there is a better way. By leveraging contemporary browser Web APIs—including the native Web Cryptography API, Web Workers, HTML5 Canvas, and the Internationalization API—every calculation, formatting routine, and cryptographic hash executes inside your device's memory. Advertising is separate: after you accept cookies, Google AdSense may set cookies to show ads. Those cookies are not your tool input.

Technical Architecture & Core Tenets

On-device tool input

Text, files, tokens, and calculations stay in the browser. OmniTools does not run its own analytics. Ads use cookies only after you accept them.

Zero Latency & Instant Output

Without HTTP request handshakes, server cold starts, or database queries, operations complete at bare-metal CPU speed in sub-millisecond frames.

Progressive Web App (Offline-First)

OmniTools is fully service-worker cached. You can install it on macOS, Windows, iOS, or Android, disconnect from Wi-Fi, and work uninterrupted in flight or remote environments.

Open RFC & Web Standards

Calculators strictly conform to international standards: RFC 8259 (JSON), RFC 2104 (HMAC), RFC 4122 (UUID v4), RFC 4648 (Base64), and WCAG 2.1 AA contrast equations.

How to check where your input goes

You can confirm that tool input stays in the browser:

1

Open Chrome, Firefox, Safari, or Edge and press F12 (or Cmd + Option + I) to launch Developer Tools.

2

Navigate to the Network tab and select the Fetch/XHR filter to monitor real-time network payloads.

3

Type, paste tokens, or format JSON. Tool actions do not send that input to an OmniTools server. If you accepted ads, you will see requests to Google's ad domains. Those requests are the ads, not your document.
