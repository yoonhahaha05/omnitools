Overview & Algorithmic Mechanics

Hex shows each byte as two digits from 0-9 and a-f. "Hi" is UTF-8 bytes 48 69. The same bytes can be printed with spaces, as a raw string 4869, or in C-style 0x48 0x69. Decoding reverses that. Odd-length hex is incomplete, because a byte is always two digits.

Worked example. "A" is 41. The word "cat" is 63 61 74. A C-style dump of "A" is 0x41. URL-style percent encoding is a different notation: %41 is also "A", but this page prints hex bytes, not percent escapes. Use the URL encoder for percent encoding.

Worked uses

  • A: hex 41, or 0x41 in C style.
  • cat: 63 61 74.

Technical Capabilities

  • Format options: space separated, C-style 0x notation, raw string
  • Handles full UTF-8/ASCII bytes

Frequently Asked Questions

What is Hexadecimal?

Hexadecimal is a base-16 numerical system representing each byte as two characters from 0-9 and a-f.

Are letters case-sensitive when decoding?

No. 4A and 4a are the same byte.

What if the hex string has an odd number of digits?

The last digit is not a full byte. Drop it or add a leading zero before you trust the decode.
